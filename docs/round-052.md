## 范围

1. 客户端注册并立刻登录。用户名 3–32 位字母、数字或下划线；密码至少 8 位。无手机号、邮箱和找回密码。
2. 本机显式「允许我的账号连接」后才 `device_online`。关掉或退出后列表里离线，不能连。
3. 已登录的协助端看到自己的设备列表。在线设备点连接，不输入会话码，不弹配对窗。改动默认仍弹确认。
4. 协助会话增加「查看服务状态」。
5. 无人值守在允许连接之后单独开启。「人不在时改动不再询问」默认关。「登录 Windows 后自动等待」默认关，打开后写入当前用户的 Run 启动项。
