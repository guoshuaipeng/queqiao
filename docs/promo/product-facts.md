# 产品事实：鹊桥远程协助

起草宣传文案时以此为准；安装包文件名、体积以官网 / Release 当前页覆盖。

## 定位

亲友 / 同事 / 客户支持场景下的**远程协助**：对方装轻量客户端，协助方用命令查看进程、日志、文件；**真正改电脑时必须在被协助本机点允许**。不是完整远程桌面，不做键鼠注入。

## 品牌

- 中文全称：鹊桥远程协助 · 智能体
- 简称：鹊桥
- 英文暂定：Queqiao Remote Assist

## 差异点（可对外）

- 一打开就能「请人帮我 / 我帮别人」
- 复制连接凭证 → 对方粘贴连接，无需填 IP
- 写操作本机确认（白话说明 + 允许 / 拒绝）；拒绝则未做任何改动
- 被协助端可见「对方做过的事」审计
- 信任三档：每次询问（默认）/ 宽松 / 完全信任（仅本会话）
- 不做完整远程桌面画面控制

## 平台口径

- 当前主推：**Windows** 安装包
- macOS / Linux：没有稳定对外包之前，文案写「以官网下载页为准」，勿写死可下
- 开源协议：以仓库为准（对外可写开源；具体 SPDX 以 LICENSE 为准）

## 勿对外宣称（当前）

- 短码单独即可安全连接（R050 未落地）
- MCP「装完就能用」（需本机构建 `RemoteAssist.Mcp.exe`；未打进安装包前勿写死）
- 完整远程桌面 / 键鼠注入
- 未核实的「吊打向日葵 / TeamViewer」对比
