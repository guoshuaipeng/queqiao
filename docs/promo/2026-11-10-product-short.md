## ④ 知乎回答 / 专栏可用中篇

**标题备选**

- 有没有比远程桌面更安心的「帮爸妈修电脑」方式？
- 远程协助一定要接管对方屏幕吗？

**正文可粘贴**

帮家人或同事修电脑时，我最烦两件事：一是教对方装复杂的远程桌面软件；二是一旦连上，对方几乎把整台电脑画面交给你，自己心里也不踏实。

所以我做了（也在用）「鹊桥」这条路径：

1. 对方安装后点「开启接受协助」，复制连接凭证发给你；
2. 你粘贴连接，先查进程、日志、文件；
3. 真正要改配置、重启服务、动文件时，对方本机会弹出白话确认——允许才执行，拒绝则未做任何改动；
4. 对方还能在界面看到「你做过的事」。

它不是要替代所有远程桌面场景（比如需要看 UI 操作的演示），而是把「查清问题 + 受控改动」做得更轻、更可控。

官网与 Windows 下载：http://121.196.45.81/  
开源：https://github.com/guoshuaipeng/remote-assist
