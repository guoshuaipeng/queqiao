# 鹊桥官网体验改版方案（静态草案 · 保留既有下载方向）

> **状态**：方案阶段，供产品差量评审；**未放行编码 / 不上线 / 不 push / 不联网改仓**。  
> **时间**：2026-11-06 Asia/Shanghai  
> **本目录**：`proposal.md`、`content-checklist.md`、`desktop-preview.*`、`mobile-preview.*`。  
> **事实来源说明**：下文「服务端中期报」等为**产品转述**，本轮设计**不当作已核验原始证据**。

## 0. 本轮设计决定（主方向）

| 决定 | 说明 |
|------|------|
| **保留既有下载资产** | 改版**默认不再**采用「暂不提供下载 / 现在不能下载」作为主设计 |
| **主 Windows、次 Linux** | 两个入口都在信息架构里；Linux **不消失** |
| **真实 URL 待回** | 最终 href 等服务端回传后再映射；**不造 URL、不造版本号** |
| **HEAD 200 ≠ 验收** | 产品转述：服务端中期报 3 个下载 href `HEAD` 为 200，**原始证据未回**；**不等于**包内容、版本、安装可用性或公网完整可用保证 |
| **主 CTA 非留联** | 首屏主行动为获取/下载 Windows；留言咨询保持次要自愿（`/ask`） |
| **能力不虚构** | 正文保持中性用途；远程桌面键鼠/文件传输/无人值守等**勿让公众误读为已支持**；真实能力一句话 **待客户端核实**（图外占位） |

预览 = **待映射既有 href 的视觉草案**，不是「已验包可安心下载」的承诺。

## 1. 用户可见信息架构

### 1.1 导航

如何使用 · 获取软件 · 帮助 · 安全与隐私 · 留言咨询（次要 → `/ask`）

### 1.2 首屏

- **标题：** `帮亲友处理电脑问题，少一点来回解释。`  
- **副文：** `鹊桥帮助亲友远程处理电脑问题。使用前请先阅读本页说明。`  
- **主 CTA：** `获取 Windows 版`（或同义 `下载 Windows 版`）— 视觉上指向本页获取区；**实现时映射既有 Windows 下载 href（待服务端回真实 URL）**  
- **次 CTA：** `第一次怎么用`  
- **再次级：** `留言咨询`

图外注明：主按钮仅为设计示意，**非**已完成包/安装验收。

### 1.3 获取软件（主 Win / 次 Linux）

**Windows（主）**

- 按钮：`获取 Windows 版` / `下载 Windows 版`  
- 旁注（用户可见、短）：`请在电脑上下载并打开。`  
- **不写**版本号、大小、校验（待核定后另补）  
- **不写**「已验证」「官方认证」等

**Linux（次）**

- 次级文字链或次按钮：`获取 Linux 版`（样式弱于 Windows）  
- **不写**支持范围、发行版列表、是否推荐（未核）  
- 入口**保留在设计中**；去留若与现网资产冲突，由服务端核验 + 产品收口，设计不擅自删除

**禁止在本区：**「暂不提供下载」「现在不能下载」、假链接、编造 URL。

### 1.4 第一次怎么用

**需要帮助的人**

1. 在电脑打开鹊桥  
2. 开启接受协助，把**完整连接凭证**私下发给信任的人  
3. 结束后，由需要帮助的人在**本机停止接受 / 结束协助**

**来帮忙的人**

1. 在电脑打开同一鹊桥  
2. **整段粘贴**对方发来的完整凭证后，**必须明确点「连接」**（不自动连接）  
3. 协助完成后可断开  

**凭证不完整时：** 请对方重新复制完整内容再发送；**不教用户自行补字段**。

不承诺具体连接确认弹窗（机制图外·客户端待核）。不用未发布客户端按钮名冒充现行说明。

### 1.5 安全与隐私（用户可见）

> 仅与信任的人协助，保管好连接凭证；结束连接不代表凭证永久失效。

### 1.6 常见问题（含失败恢复短句）

- 怎么开始？→ 见「第一次怎么用」。  
- 手机能装吗？→ 请在电脑上下载和使用；手机可阅读说明。  
- 是两个软件吗？→ 同一个程序，用法不同。  
- 提示凭证不对或不完整？→ 请对方重新复制完整凭证再粘贴，不要自己改内容。  
- 点了连接但没连上？→ 检查网络，确认双方都已打开，需要帮助的一方已开启接受；稍后重试。  
- 想留言？→ 可自愿留言咨询。  

正文**不**列举未核实的远控能力清单。

### 1.7 用途表述（中性）

正文只用「帮助亲友远程处理电脑问题」一类中性用途。  
**不要**写或暗示：完整远程桌面键鼠、文件传输、无人值守等（除非客户端核实后产品另授文案）。

## 3. 图外待核项（有结果后再固定文案）

1. **真实下载 URL**（Windows 主、Linux 次）— 等服务端回传后再写入实现映射。  
2. HEAD200 原始证据与包文件、版本、安装步骤是否验收通过。  
3. **真实能力一句话**（客户端核实）：是否/如何描述键鼠控制、文件、无人值守等——未核前正文保持中性、不虚构。  
4. 连接过程是否另有确认 UI；写操作请求规则。  
5. 版本/大小/校验等元数据是否对外展示。  
6. 隐私政策等页脚链接。  
7. 账号免密类旧主推是否已降级（建议降级，待产品确认现网文案）。  
8. 现网与嵌入 HTML 一致性；改 HTML ≠ 上线。

**设计不替代产品做「可正式公开下载 / 能力已具备」的发布决定。**

## 附录 A — 下载相关条件判断（仅文档，非主设计默认）

主设计已采用「**保留既有下载资产**」。下列条件仅供收口时对照，**避免再把未核写成未发布**：

| 条件 | 含义 | 与主设计关系 |
|------|------|----------------|
| 既有 href 仍应保留在改版信息架构中 | 本轮默认 | **主路径** |
| `HEAD` 200（产品转述中期报） | 连通性线索；证据未回 | **不**当作安装/内容验收 |
| 授权 + 可验证包 + 核定元数据 | 若具备，可在旁注补版本等 | 增强，非本预览已具备 |
| 产品**确认**某入口应下架 | 才可从信息架构移除 | 未确认前不按「暂不提供」改主设计 |
