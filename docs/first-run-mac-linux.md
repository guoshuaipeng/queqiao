# 鹊桥 · Mac / Linux 首次使用文案

> 产品收口：2026-11-05 Asia/Shanghai。体验起草原文，产品写入仓库。品牌名统一为「鹊桥」（来稿「鹃桥」已改）。
> 亲友和客户的主路径以下一阶段 Avalonia 被控窗为准，不要把「打开终端复制码」写给他们。
> CLI 展示和终端确认只给会用终端的同事运维，也可供 R009 直接用字，但不扩大 R009 范围（本轮不要求 Avalonia）。
> 信任等级不另写，沿用 `docs/trust-levels.md`。
> 安全底线与 Windows 相同：公网中继、两行会话码+验证密码、写操作本机确认、不做远程桌面；界面不出现 Assist、Admin、ownerLink、TLS、端口号。
> 场景闭环见 `docs/mac-linux-scenes.md`。

## 结论

1. 亲友 / 客户：装好后打开被控窗，点「复制码+密码」，写确认弹窗与 Windows 同一句「对方想在这台电脑执行操作」。关窗不等于结束协助，要有「结束这次协助」。
2. 同事运维的 CLI：终端打印与 Windows 相同的两行文本，并尽量自动复制；终端确认标题、人话、次要命令原文、「允许 / 拒绝」、60 秒超时自动拒绝，都与 Windows 对齐。
3. 需要另装依赖时只装「.NET 8 运行时」，不要装 SDK。体积用一句话说清「小包要先装运行时 / 大包已经带上了」。
4. 不要套 Windows「点允许连网」的话术。

## 1. 亲友 / 客户：安装说明（发给对方）

只在对方打开时报缺少 .NET、或分发的是未自包含的程序时，才加上「先装运行时」那几行。自包含的包不要把装运行时写进主路径。

### macOS

我发你一个安装包，名字叫「鹊桥远程协助」。
打开后把「鹊桥」拖进「应用程序」，再从那里打开它。
如果打开时提示缺少 .NET，先安装「.NET 8 运行时」（用来跑这个程序的，不是开发工具）：
打开 https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0
在「运行时」那一栏下载 macOS 的安装包，不要选 SDK。近年的 Mac 选 Arm64；装不上再换 x64。
如果电脑说无法验证开发者，到系统设置里选「仍要打开」。
打开后点「复制码+密码」，把复制出来的发给我。

### Linux

我发你一个压缩包，名字叫「鹊桥远程协助」。
解开后打开里面的程序。如果点不开，告诉我一声（可能需要先允许这个文件运行）。
如果打开时提示缺少 .NET，先安装「.NET 8 运行时」（用来跑这个程序的，不是开发工具）：
打开 https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0
在「运行时」那一栏按你的系统选 Linux，不要选 SDK。
打开后点「复制码+密码」，把复制出来的发给我。

复制出来的仍是两行「会话码：… / 验证密码：…」，Windows 协助端一次粘贴即可。

## 2. 亲友 / 客户：被控窗

- 出示凭证：与 Windows 一样的「复制码+密码」，不要让他们去终端里手选。
- 写确认弹窗与 Windows 已验收原文对齐：标题「对方想在这台电脑执行操作」；人话是主说明，命令原文放在「命令：」后面；按钮「允许 / 拒绝」；「若不操作，将在 60 秒后自动拒绝。」超时不自动允许；拒绝后「已拒绝，未做任何改动。」
- 配对确认（访客）沿用 Windows：「有人想协助这台电脑」；「允许协助 / 拒绝」；「若不操作，将在 30 秒后自动拒绝。」
- 收尾：关窗不等于结束协助。窗口上要有明确的「结束这次协助」。关闭窗口时提示：「关闭窗口后，协助可能还在进行。要结束请点「结束这次协助」。」
- 刷新会话码后：旧码旧密失效。
- 信任等级沿用 `docs/trust-levels.md`，不另写。CLI 阶段没有「高级」设置，只保留默认「每次询问」。

## 3. 同事运维：CLI 如何展示会话码

启动成功后打印：

鹊桥远程协助已启动，正在等待对方连接。
把下面两行发给要帮你的人：
会话码：AB12CD
验证密码：3471

同时尽量把这两行复制到剪贴板（格式与 Windows「复制码+密码」完全相同）。复制成功后再加一行：「已复制，直接发给对方即可。」失败则写：「用鼠标选中上面两行，复制后发给对方。」
已有人连上时换成：「已有人连上。对方可以查看进程、日志和文件；要改动时会再问你。」
刷新后打印：「已换新的会话码和验证密码。之前发出去的码不能再用。」然后再次打印新的两行。

## 4. 同事运维：终端确认（与 Windows 对齐）

标题：对方想在这台电脑执行操作
人话例如：删除一个文件或文件夹
次要：命令：rm /tmp/demo.txt
提示：请输入 允许 或 拒绝（也可以输入 y 或 n）。
若不操作，将在 60 秒后自动拒绝。

允许 / y / Y 视为允许；拒绝 / n / N 视为拒绝。超时不自动允许。拒绝后打印：已拒绝，未做任何改动。不要在终端里再发明一档信任等级。

## 5. 体积 / 依赖

没有实测体积前不要写兆数。小包：「这个程序比较小，但需要先安装「.NET 8 运行时」。装一次就可以，它不是开发工具。」
大包：「安装包会比较大，是因为已经包含运行所需的组件，你不用再另外安装东西。」
必须和实际分发一致。
