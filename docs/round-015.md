R014 已产品验收 Linux Avalonia 账号登录 → 自有设备列表 → 免密连接，以及「最近审计」人话。设备列表仍同时显示内部 id（如 dev-living）与人话名称；选中在线设备后「连接：{名称}」仍是灰色次要样式，和禁用态靠文案才能区分。本轮把这两处改到亲友能一眼看懂、一眼看出能点。

## 本轮目标

1. **高频**：Linux Avalonia 自有设备列表只显示人话名称 + 在线/离线，不展示内部 id；选中在线设备后「连接：{名称}」必须是明确可点击的实心样式；选中离线设备时连接不可用，并提示「这台电脑现在不在线」。
2. **打磨**：补一张免密已连接后「常用操作」三个按钮已可用的截图（查看正在运行的程序 / 查看日志 / 运行一条命令）。

## A. 设备列表人话与连接态（高频）

验收：
- 列表每一行只显示人话名称（如「客厅电脑」）和「在线」/「离线」，不出现 dev-living、dev-office、deviceId 或其它内部编号。
- 未选中时「连接这台电脑」（或同等文案）保持灰色禁用，并提示「请先点选一台自己的电脑」。
- 选中「在线」设备后，按钮文案为「连接：{名称}」，旁注不要改 R014 已验收的「将免密连接「…」」；按钮必须换成明确可点击的实心样式（建议实心绿，与上方会话码「连接」一样表示可点）。禁用态保持灰色不可点。两者要能一眼分开，不能只靠文案。
- 选中「离线」设备时，连接按钮不可用（灰色），并提示「这台电脑现在不在线」（或同等人话；不要出现 offline、deviceId、端口号）。
- 亲友界面不出现 Assist、Admin、ownerLink、TLS、端口号、内部 id。品牌「鹊桥」。
- osx 能出包即可；未上真机就注明，不写成 Mac 已验收。

截图放到 `docs/screenshots/r015-*`（至少：列表无内部 id；选中在线后连接按钮为实心可点；选中离线后连接禁用并有人话提示）。

## B. 免密连上后常用操作可用（打磨）

- 免密连接成功后，「常用操作」里「查看正在运行的程序」「查看日志」「运行一条命令」应可用，不要仍是连上之前的灰色禁用。
- 不要改 R014 已验收的账号/密码标签、免密成功文案「已用你的账号连接，无需再确认配对（写操作仍须对方本机确认）」、审计人话，也不要改 R013 已验收的已确认列表标题和刷新确认原文。
