# 开发约定

## 协作

- 决策与分工一律写进本仓库 `docs/`，**禁止只依赖聊天记忆**。
- 需求队列唯一入口：`docs/PRODUCT-VERSIONS.md`（标「待开发」才推进；草稿 / 暂停不动）。
- 改动前先在文档标明本轮负责模块，避免互相覆盖。
- **不改 AI-SSH-Pro**；本仓库独立演进。
- 本机开发；本地 commit 可，**不 push / 不上公网**，除非用户另说。推送前看清未提交文件。

## 模块边界

| 模块 | 路径 | 边界 |
|------|------|------|
| 桌面客户端 | `apps/queqiao-tauri` | 唯一桌面客户端（Tauri）；不改 `relay/` 协议字段 |
| 公网中继 | `relay/` | Go + SQLite；协议变更先改 `docs/relay-protocol.md` 再改代码，客户端跟随文档 |
| 官网 | `site/` | 独立进程、分库；官网改版已暂停，交由其他人制作 |

## 技术红线

- **默认连接路径 = 公网中继**（访客 code+密码，或账号设备免密）；LAN 仅可选/调试。
- 写操作必须被控本机确认，不可由中继 / 协助方绕过。
- 密钥、会话码、审计日志、`relay/data/*.db` 不进 git。
- 控制协议为 **JSONL**（不是空格分隔文本行）。
- **编译通过 ≠ 运行验收**；**本地 PASS ≠ 公网已部署**，报告须分列。

## 界面预防（本表不超过 15 条）

1. 会隐藏的区块若写了 `display`，必须同时写 `[hidden] { display: none !important; }`。
2. 空闲启动只渲染首页；会话、设置、信任条、弹窗靠真实状态出现。
3. 弹窗没有标题和正文就不得显示按钮。
4. 确认类弹窗默认焦点在拒绝/取消；超时走拒绝。
5. 截图里的「已连接」不能当成已经连上，先看是不是样式把隐藏冲掉。
6. 桌面验收用窗口自身画面；浏览器图单独命名，不冒充桌面。
7. 窄于 760 时上下排列。展开记录后往下滚，仍能点到「连接」，粘住的开启按钮不能盖住它。
8. 项目没有深色主题就不为测试加一套。
9. 演示数据只放测试夹具；安装后的窗口不读取 `uitest`。
10. 复制失败就提示失败；不把凭证写进日志。成功提示只在读回内容与凭证一致时出现。
11. 停止接受先作废这一代，再关套接字。序号更旧的画面不再画上来。
12. 确认弹窗用实底遮罩。弹窗开着时，不要把连接原文画在后面。
13. 结束本次协助后双方回到首页。同一份凭证不能再进这一次。
14. 对方不在等待时不要只说检查网络。被拒绝的改动不得执行。
15. 改动只有点「允许」后才执行，按钮显示剩余秒数；超时和拒绝都不执行；确认框直接写出命令，执行完清掉命令；只查看不弹确认。宽松档普通改动可不问，删除和关机仍要点允许；完全信任只在这次会话，结束后再连不沿用。结果区离开最底下才停住跟随，回到最底下后新输出继续跟随；翻历史结果不影响当前结果框。横滑不带动整页，整页滚动不改变横滑位置；短行留在左边，长行可滑到行尾且位置保持。滚轮在结果框内翻，到顶/到底不带动整页；框自己滚不动时滚轮也不带动整页。出现横滑条后整页不再多竖条；横滑条坐在文字下面，不切掉最下面一行；长行不被小滚动条挡住。窗口缩到最小高度后关键操作仍完整可见、不多出竖向滚动条；展开历史结果要能看到上一次输出、末行完整；常用操作那一排不被上沿切成半个按钮。
