## 本轮目标

1. **高频**：协助端 / 设置里能看到怎么安装 MCP，不用另翻仓库文档
2. **打磨**：已连上网络时收起「请点允许」横幅；横幅里「设置」不要折成「改设 / 置」

## A. 界面上的 MCP 安装方法

给协助方（要用智能体连上会话的人看），不要放进被协助端亲友主路径。仅接受协助时仍不自动对外监听 MCP。

入口：协助端或设置中的「如何安装 MCP」（可与「复制 MCP 配置」放在一起）。

步骤（界面上直接写出来）：

1. 点「复制 MCP 配置」
2. 打开 Cursor（或同类工具）的 MCP 设置，粘贴进去并保存
3. 刷新或重启后再用智能体协助；对方电脑上要改动的操作仍会弹确认，智能体不能绕过

验收：协助端不打开仓库文档，也能完成「复制配置 → 贴进 MCP 设置」。被协助端默认首屏仍不出现 MCP。详细参数仍以 docs/MCP.md 为准。

## B. 联网横幅收口（体验，不阻塞 R003）

- 已显示「已连上网络，可以发给对方了」时，顶部「请点允许」横幅自动消失。
- 只有还没连上，或用户点了「我点了取消」时才显示；取消后改为恢复步骤（打开防火墙设置、勾选允许）。
- 横幅整句不要把「设置」折成「改设」和「置」两行。
