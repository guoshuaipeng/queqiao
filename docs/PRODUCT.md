# 鹊桥远程协助 · 智能体 — 产品决策

## 品牌名

- **中文全称**：鹊桥远程协助 · 智能体
- **简称**：鹊桥
- **英文（暂定）**：Queqiao Remote Assist
- 意象：像鹊桥一样把两边连上，用智能体/命令协助修电脑（非远程桌面画面）。

> 独立软件 + 可 MCP 嵌入其他智能体。不做进 AI-SSH-Pro。
> 约定与决策写进本仓库 `docs/`，**不要只放在聊天记忆里**。

## 定位

对标向日葵 / TeamViewer 的「远程协助」场景，但**控制面不是远程桌面画面**，而是 **命令 + 智能体**：对方装轻量被控端，协助方（人或 AI）连上后查进程/日志/文件；**危险操作必须在被协助本机确认**后才执行。不做完整远程桌面 / 键鼠注入。

## 目标用户

亲友 + 客户支持 + 同事运维兼顾。

## 连接

1. **默认：公网中继**（Go `relay/`；开源客户端默认本机 `127.0.0.1:17891`，正式地址见 `docs/relay-deploy.md` / `private.example/deploy.md`；客户端仍可改）。
2. **访客协助（当前安全主路径）**：被控端展示会话码与验证码（短形态可展示/口述）；主按钮 **「复制连接凭证」** 复制**完整安全载荷**（`remoteassist:pair`，含 code + password + **Agent 业务证书指纹 `fp=`**）。协助端**一个**输入框粘贴该整段后点「连接」。短码或无指纹旧两行可识别但**必须阻断**并人话请对方重发完整凭证。**客户端不得以填局域网 IP/端口/TLS 指纹为主操作。**
3. **账号设备免密（2026-11-09 拍板恢复）**：见下节「账号与设备免密」。亲友临时协助仍用连接凭证，不强制登录。
4. **局域网直连**保留为高级/调试（历史端口 `17890`，载荷 `via=lan`），非默认。
5. 中继控制面：**JSONL**（见 `docs/relay-protocol.md`）；配对后透明转发。业务层默认 TLS + 证书指纹钉扎（端到端，中继只转发）。`--insecure` 仅显式调试。
6. **业务 TLS 与分享**（见 `docs/tls-trust.md`）：E2E TLS + Agent 临时证书指纹钉扎；默认分享须带完整安全载荷（含 `fp=`）。`{会话码}-{8位验证码}` 只授权中继会话，不能单独建安全业务通道；禁止 TOFU；缺指纹安全阻断，禁止自动降明文/skipTls。

## 体验目标

> **产品意图**，与「安全实现前置条件」分节。短码本身**不等于**已可安全连接；落地前连接仍走完整安全载荷。

1. **复制内容 = 会话码 + 密码（短码）**：主路径目标为 `{会话码}-{8位验证码}`（8 位验证码要求仍有效）。中继地址默认内置，只在**高级设置**修改；亲友**不**复制地址或长串载荷。协助端一次粘贴短码连接——**前提**见下节。
2. **单主窗口**：首页与点击「去协助 / 接受协助」后共用**一个**主窗口，页内切换，不多开主窗口；返回首页不叠窗，保持位置/大小。有活动会话时返回首页或切换角色**不得**暗中断开、留下隐藏会话或自动扩大权限；确需结束须本机确认。**安全确认对话框不在单窗口合并范围**——不得为单窗口取消写操作本机确认。

## 安全实现前置条件（短凭证 / R050）

- **当前**安全连接仍要求完整 `remoteassist:pair`（含 Agent 业务 TLS 指纹 `fp=`）。信任模型见 `docs/tls-trust.md`，**不得削弱**。
- 短码今日只授权中继会话，**不能单独**建安全业务通道。
- **禁止**：TOFU；跳过校验；把中继回传、未经可信绑定的指纹当独立认证；未验证前把主路径改成「只复制短码却暗连」。
- **R050（短码可连）仍 blocked**：产品意图已锁定（唯一连接凭证 = code + 8 位密码；服务端不知明文密码，实现用成熟 **PAKE**，禁止自造密码学），但**未授权实现**；须通过含恶意中继在内的安全验收后才可宣称。见 `docs/roadmap.md`。

## 账号与设备免密（2026-11-09 拍板）

用户明确要求包含账号、设备列表、免密连接、运维和无人值守。

- **注册**：客户端内用户名 + 密码，成功后立刻登录。用户名 3–32 位字母、数字或下划线，不区分大小写。密码至少 8 位。不收手机号和邮箱，不提供找回密码。
- **免密范围**：只有这台电脑在本机打开「允许我的账号连接」之后，同一账号才能从设备列表连上。账号令牌不能连上一台从未允许过的电脑。
- **安装 ≠ 可被随时控制**：安装/启动/上线本身不授予远程控制。
- **写操作**：默认仍在本机确认。无人值守里的「改动不再询问」默认关闭，要单独确认。
- **短码**（R050）仍不在这一版。
- 账号仅用于发现与连接授权；不做完整云端用户中心 / 计费 / 组织工单。

## 鉴权与安全底线

- **访客**：中继 `guest_host` / `guest_join`（code + 密码；**新生成/刷新验证码固定 8 位数字**，字符串保留前导零）。人话主路径复制/粘贴为**完整安全载荷**（含业务指纹）；短码仅展示/口述；无指纹输入须阻断；刷新会话码须同时换密码。
- **账号**：中继 `signup` / `login` → `token`（约 7 天）→ `device_online` / `list_devices` / `connect_device`。轻量存储即可。
- **写操作本机确认不可绕过**（除非对方主动授予 Admin）。中继配对成功 ≠ 授权写操作。
- 审计写本地日志；敏感路径可读拒绝。

## 权限三级

1. **Guest（访客只读）**
2. **Assist（默认）**：写操作本机确认
3. **Admin**：可跳过部分确认（仍审计）；仅对方主动授予

协助权限与信任等级（每次询问 / 宽松 / 完全信任）正交：不得把「服务器不可冒充」落实成强制每次写弹窗，也不重置既定三档。

## 产品形态与安装

- **一个窗口、两件事**：打开就能「请人帮我」和「我帮别人」。界面以 `docs/CLIENT-UI.md` 为准。
- **客户端**：只有 Tauri（`apps/queqiao-tauri`）。.NET / WinForms / Avalonia 客户端已删除，不要恢复。
- **可选 MCP**：设置里可复制 MCP 配置，供协助方 Agent 使用；与界面共用同一连接和确认流程。实现为 Rust stdio `RemoteAssist.Mcp`（见 `docs/MCP.md`）；本机需先 `.\scripts\publish-mcp.ps1` 或自备同名 exe。
- 被控：主界面展示会话码、密码和连接凭证。
- 控制：粘贴完整连接凭证后点连接。中继地址默认内置，只在设置里改。

## 支持平台

- 桌面客户端为 **Tauri**：Windows / macOS / Linux（x64）均可下载；Linux 另提供 MCP 命令行包。以官网 `/downloads/` 实际文件为准。
- 写操作本机确认在所有平台上都是同一条安全底线。

## 协助闭环（管理端 / Agent）

1. 协助方把**安装包下载地址**或本机安装包发给远端用户。
2. 远端安装后，把 **完整连接凭证**（当前：「复制连接凭证」得到的整段安全载荷；目标主路径：会话码+8位密码）回传协助方。
3. 协助方（人或 Agent）连上会话，排障；写操作走本机确认。

## 确认与审计

配对与写操作默认本机确认窗；串行排队；审计写本地日志。写操作必须在被控本机确认，中继配对成功 ≠ 授权写操作。亲友可见界面不出现 Assist、MCP、ownerLink、TLS。

**中继会话码审计**：中继 SQLite `guest_audit` 表记录会话码生成、join 成功/失败、会话结束，供鉴权后的管理台只读列表；**不**存不展验证码、password_hash、fp、完整连接凭证；**不**改 guest_* 协议字段。见 `docs/relay-audit.md`。官网 `/admin` 会话码只读列表已完成（仅本地验收，见 `PRODUCT-VERSIONS.md` PV-001）。

被协助的人可以在本机设置信任等级（对方不能远程打开），详见 docs/trust-levels.md：

- 每次询问（默认）：所有写操作都弹确认。
- 宽松：高风险仍要确认；其余自动允许并记审计。高风险包括删除文件或文件夹、格式化、关机/重启、改用户或权限、改注册表；「执行命令」若明显命中这类意图也仍要问。这不是完美安全网，所以默认必须是「每次询问」。
- 完全信任：本会话写操作不再弹窗，仍记审计。打开前本机再确认一次；可随时改回；会话结束或换人后不沿用到下一个访客。

访客只读仍是天花板：完全信任也不能让访客写。协助权限决定对方能提议什么，信任等级决定本机还问不问。界面不出现 Assist、Admin、ownerLink。

- 配对确认窗：「有人想协助这台电脑。对方可以查看进程、日志和文件，不能直接改你的电脑。真正要改动时，还会再问你。」按钮「允许协助 / 拒绝」；超时自动拒绝。账号免密连本机已允许的设备可跳过此窗，写操作窗仍在。
- 写操作确认窗：「对方想在这台电脑执行操作」+ 该次操作的白话说明 +「允许 / 拒绝」。超时不自动允许；拒绝后提示「已拒绝，未做任何改动」。

## 官网与接单

- 静态产品介绍 + 接单表单 + 极简后台（订单状态三档 + 按联系方式聚合的客户名单）。详见 `docs/site.md`。
- 必须轻便：静态页 + 小进程 + SQLite；不装 Node/Java/PHP/MySQL/WordPress/Docker 全家桶；不占用中继 17891。
- 与中继账号/设备体系分开；不因此做成完整云端用户中心、计费或组织工单。
- **官网改版已于 2026-11-06 暂停，交由其他人制作**；本仓不主动改版官网。
