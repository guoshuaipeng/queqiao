# 远端协助 — 产品决策

> 独立软件 + 可 MCP 嵌入其他智能体。不做进 AI-SSH-Pro。
> 约定与决策写进本仓库 `docs/`，**不要只放在 bot 记忆里**。

## 定位

帮别人修 Windows：对方装轻量被控端，协助方（人或 AI/MCP）连上后查进程/日志/文件；**危险操作必须在被协助本机确认**后才执行。不做完整远程桌面。

## 目标用户

亲友 + 客户支持 + 同事运维兼顾。

## 连接（2026-11-05 起）

1. **默认：公网中继**（Go `relay/`，建议阿里云 2C2G，可用纯 `IP:17891`）。
2. **被控端**出示 **会话码 code + 验证密码**；**控制端**输入后经中继配对。
3. **局域网直连**保留为高级/调试（Agent 仍监听 `17890`；载荷 `via=lan`）。
4. **传输**：业务仍默认 TLS 1.2/1.3 + 证书指纹钉扎（端到端，中继只做透明转发）。`--insecure` 仅调试。
5. **账号（最小闭环）**：中继上 `AUTH REGISTER/LOGIN` 拿 token；被控 `DEVICE ONLINE` 上线；控制端 `DEVICE LIST` + `DEVICE CONNECT` **免密**控制自己的机器（业务层 `ownerLink` 自动批准 Assist）。

详见 `docs/relay.md`。

## 鉴权

- **访客协助**：一次性 **code + 密码**（刷新会话码会同时换密码）；配对成功后仍发短时业务 token（约 2 小时）。
- **账号免密**：同一账号下已绑定且在线的设备；控制端登录后从设备列表连接，无需对方 code/密码（仍走本机审计；写操作仍要被控确认，除非 Admin）。
- 中继层校验会话密码 / 账号 token；**不做**完整用户中心/计费（MVP 本地 JSON 存储）。

## 权限三级

1. **Guest**：列进程、读日志、列目录、读文件（敏感路径可拒绝）。
2. **Assist（默认）**：只读 + 提议命令；**对方本机确认**后才执行。
3. **Admin**：可跳过部分确认（仍审计）；仅对方在配对时主动授予。账号免密默认 Assist。

## 产品形态

- **同一 App 双模式**：接受协助 / 去协助别人；可返回首页。
- 被控：主界面展示 code、验证密码、二维码/载荷、TLS 指纹、配对与审计；可绑定账号以上线设备。
- 控制：code+密码或载荷经中继连接；设置里填中继地址；可注册/登录、刷设备列表、免密连接。
- 安装包：`installer/RemoteAssist.iss` → `RemoteAssist-Setup-*.exe`。
- 兼容：独立 Agent / Helper.UI / Helper CLI / MCP。

## MCP

- 优先通用 stdio；工具与 Helper 同一客户端协议；`run_command` 走确认流程。
- 连接参数可改为中继载荷（含 `via=relay&pwd=`）。

## 确认与审计

配对与 Assist 写操作默认本机确认窗；串行排队；审计写本地日志。

## 明确不做（当前）

- 完整远程桌面 / 键鼠注入
- 完整云端用户中心 / 计费 / 组织工单
- 修改 AI-SSH-Pro 本体
- 正式 CA 互认（仍用自签 + 指纹）

## 技术选型

- Windows 客户端：**.NET 8**（另有 `src-net48` 体积对比版，不替代主线）
- 公网中继：**Go**（或后续 Python 旁路管理；转发本身用 Go）
- 二维码：QRCoder
- 帧：4 字节 LE 长度 + UTF-8 JSON；中继透明 pipe

## 体积说明

- .NET 8 自包含安装包约数十 MB（家用机一般**不预装** .NET 8；系统预装多为 .NET Framework 4.8）。
- Framework 4.8 对比版可更小，但与跨平台中继客户端路线不同，主线暂保持 .NET 8。
