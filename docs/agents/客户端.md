## 4. Windows 主路径与 net8 冻结（站立）

- **主维护面 = net48**（`src-net48/`），亲友分发依赖本机 **.NET Framework 4.8** 小包（见 `docs/PRODUCT.md`、`docs/round-047.md`）。
- **冻结 net8 WinForms 功能迭代**：不以 `src/` WinForms 为 Windows 新功能主路径；仅 **安全 / 协议临界** 可 backport 到 net8。
- **功能对齐**：先前在 net8 迭代过的能力应迁到 net48，不留功能缺口；**例外（已废止不迁）**：账号免密 / `ownerLink` / `connect_device` / 设备密钥快捷连（见 PRODUCT「严格唯一凭证」）。
- Avalonia / CLI 服务 Mac/Linux 与兼容；**不是** Windows 亲友主路径。R047 安装说明须写清 FW4.8，**不**引导用户去装 .NET 8 当主路径前提。
- 迁移清单与建议轮次由盘点输出交产品排期；**建议主题 ≠ 已批准实现轮**。

## 5. 安全与凭证红线（实现必须遵守）

细则以正文为准，勿在本文件另立冲突规格：

- `docs/tls-trust.md`：业务 TLS **端到端**钉扎 **Agent 临时业务证书**指纹；中继不终结业务 TLS；**禁止 TOFU**；**禁止**缺指纹自动降明文 / skipTls / Insecure 主路径回退。
- `docs/quality-connection-credential.md`：当前主路径「复制连接凭证」= 完整 `remoteassist:pair`（含 `fp=`）；短码不可独立安全连接；缺 fp **人话阻断**。
- 写操作本机确认不可由 MCP / 中继绕过（与信任三档正交，见 `docs/trust-levels.md`）。
- 完整连接凭证 / fp / 密码 **不得**写入普通日志或对外异常原文。
- R043–R045 等「编译/文档 PASS_WITH_NOTES」**≠** 运行验收 **≠** 公网已验。

## 6. UI / 本机操作门槛

- **UI 大改**（含单主窗口等）：须体验方案 + **用户确认** + 产品授权后再实现；草稿与 agent 口头同意不算授权。
- **R049**（单主窗口 + 高级中继）：规格 draft / **暂停实现** 待体验与用户确认。恢复前先核对工作区实际状态（含未提交改动），**不得**在未授权时继续推 UI 或改写历史。
- **禁止**在用户本机启动应用 / UI / 测试打断用户工作（除非用户原话明确要求）；允许 **无 UI 编译** 与文档核对。
- 不杀用户进程；产物目录被占用时改用独立输出目录。

## 7. MCP 注意

- R048 已在 net48 **Helper** 补「复制安装说明 / 复制 MCP 配置 / Skill」——这是**剪贴板指引**，**不等于** net48 树内已有独立 stdio MCP 可执行宿主工程。
- 独立宿主现状：`src/RemoteAssist.Mcp`（**net8.0**）+ `scripts/publish-mcp.ps1` → `artifacts/mcp-win-x64-sc|fd/RemoteAssist.Mcp.exe`。net48 配置复制通过 `McpExeLocator` 查找上述产物路径。
- 若产品要求「net48 安装包内自带可用 MCP 宿主」，须另开正式规格（宿主迁移或打包策略），不可假定复制按钮已等于宿主已交付。
