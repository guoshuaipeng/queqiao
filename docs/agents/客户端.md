- 冷启动不监听。只有用户点「开启接受协助」才连接中继。
- Waiting 不是 Connected。配对和写操作默认在本机询问。
- 复制凭证不得假成功。取消或结束后，迟到的成功不得进入新会话。
- 完全信任只活在当前这次被协助会话里。
