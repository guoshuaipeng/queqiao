## 5. 安全与凭证红线（实现必须遵守）

细则以正文为准，勿在本文件另立冲突规格：

- `docs/tls-trust.md`：业务 TLS **端到端**钉扎 **Agent 临时业务证书**指纹；中继不终结业务 TLS；**禁止 TOFU**；**禁止**缺指纹自动降明文 / skipTls / Insecure 主路径回退。
- `docs/quality-connection-credential.md`：当前主路径「复制连接凭证」= 完整 `remoteassist:pair`（含 `fp=`）；短码不可独立安全连接；缺 fp **人话阻断**。
- 写操作本机确认不可由 MCP / 中继绕过（与信任三档正交，见 `docs/trust-levels.md`）。
- 完整连接凭证 / fp / 密码 **不得**写入普通日志或对外异常原文。
- R043–R045 等「编译/文档 PASS_WITH_NOTES」**≠** 运行验收 **≠** 公网已验。
