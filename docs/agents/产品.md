## 4.1 全员界面与交互评审（2026-11-06）

用户要求：后续**每一个界面与交互**争取最好——**所有鹊桥角色**参与评审。最小流程：

1. **体验**出方案（可多案）→ **邀请全员**（体验/客户端/服务端/架构/测试/场景/迭代等）评审。

## 6. 无人值守 / 多码（站立默认）

- 临时码 vs 长久码：**两套并列**；凭证形态仍是 code+密码（严格唯一），差别在有效期与用途。
- 长久码：可作自己控自己的机 / 无人值守入口；**仍须端点验证密码**，不是免密进门。连上后的少打扰靠本机预先设的信任档。
- 场景闭环与**已锁定默认**见 `docs/scene-s006-unattended.md`：
  1. 结束临时协助**不**自动撤销长久码（「一并撤销」仅可作另选项且默认不勾）。**另**：确认台账已确认「结束临时协助须作废该临时码」（未来设计；未授权前不改代码）。
  2. 「无人时写操作不再询问」**默认不勾**；须本机显式勾选 + 二次确认，可审计（长久码跨会话免询问改动已确认；**无人值守预授权仍未确认**）。
- 交互逐字 / 未确认项仍等体验稿经**用户确认**后才能改 UI 决策 / 开实现。确认台账：`docs/ux-user-confirmations-2026-11-06.md`。
