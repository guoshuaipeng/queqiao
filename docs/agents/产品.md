> 写入仓库供换 bot 接续（2026-11-06 Asia/Shanghai）。**决策以本文件 + `docs/PRODUCT.md` / `roadmap.md` 为准，不只保存在 bot 记忆里。**  
> 对应助手：「鹊桥-产品」。

## 1. 角色

- 定定位、优先级、取舍与实现轮授权；对照验收、收口文档。
- **少问用户**：可逆且范围内的优先级与默认值由产品自定；不可逆（推生产、改安全底线、UI 交互定稿）仍须用户或既定流程。
- 与客户端 / 服务端 / 架构 / 体验 / 场景直接协同；用户要求「交互先体验确认再开发」时，产品不代用户点头。

## 2. 品牌与平台（站立）

- **品牌**：鹊桥远程协助 · 智能体（简称**鹊桥**）。
- **Windows 主路径 = net48**（`src-net48/`），依赖系统 **.NET Framework 4.8**，亲友官网主推**几兆级小安装包**（R047），不是几十兆自包含。
- **冻结 net8 WinForms 功能迭代**：Windows 不再以 net8 WinForms 为主维护面；仅当安全/协议危及兼容时 backport。Avalonia 留给 Mac/Linux，不当 Windows 亲友主路径。
- **迁移**：凡先前在 net8 迭代过的能力，**一律迁到 net48**，不留功能缺口；**例外**：账号免密 / `ownerLink` / `connect_device` / 设备密钥快捷连 — 产品意图已废止，**不迁**，R050 收口时移除或隔离。

## 3. 凭证与安全（站立）

- **严格唯一凭证**（已拍板 2026-11-06 10:35）：连接只认 **code + 8 位密码**（当前实现主路径仍为含 `fp=` 的完整连接凭证，直至 R050）。自有设备也要输入。取消账号免密与设备密钥旁路。
- **R050**（PAKE / 短码可连）：决策锁定，状态 **blocked**；架构评估见 `docs/pake-unique-credential-eval.md`。**未授权实现前不得改主路径**；**不得宣称现网已安全满足**「服务器不知密码 / 唯一凭证」。
- 身份认证与写操作确认**正交**：服务器不能因安装/上线自取控制；协助者确认档位仍按本机三档，不强制每次弹窗。
- S1 密封指纹仅为过渡/对照，≠ 最终唯一凭证目标（见 `docs/short-credential-trust.md`）。

## 4. UX / 实现门槛（站立）

## 6. 无人值守 / 多码（站立默认）

- 临时码 vs 长久码：**两套并列**；凭证形态仍是 code+密码（严格唯一），差别在有效期与用途。
- 长久码：可作自己控自己的机 / 无人值守入口；**仍须端点验证密码**，不是免密进门。连上后的少打扰靠本机预先设的信任档。
- 场景闭环与**已锁定默认**见 `docs/scene-s006-unattended.md`：
  1. 结束临时协助**不**自动撤销长久码（「一并撤销」仅可作另选项且默认不勾）。
  2. 「无人时写操作不再询问」**默认不勾**；须本机显式勾选 + 二次确认，可审计。
- 交互逐字仍等体验稿经**用户确认**后才能改 UI 决策 / 开实现。
