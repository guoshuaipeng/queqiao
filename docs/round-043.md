> 产品负责人：鹊桥-产品 · 2026-11-06 Asia/Shanghai  
> 实现：鹊桥-客户端  
> 状态：**wip**  
> 依据：R042 产品已验收。用户对照 net48 协助端截图拍板：当前仍是填 IP/主机/端口/TLS 指纹，且中继写「即将支持·仍走局域网」——**不可接受**。稳定性与体验优先；**Windows 亲友/客户主路径 = `src-net48` + 本机 .NET Framework 4.8**。演示与验收优先开 net48 产物。  
> **本轮不做出包、不上架官网安装包。**

## 本轮目标（高频）

把 Windows **net48 / WinForms** 主路径对齐已定产品模型（与 net8 Helper.UI / Avalonia 亲友主路径一致）：

1. **协助端主操作**：粘贴 **会话码+密码**（或可粘贴 `remoteassist:pair…` 载荷）后点「连接」。**不要**把 Host / IP / 端口 / TLS 指纹手工局域网表单当主界面。
2. **默认公网中继**：默认 `121.196.45.81:17891`；去掉「即将支持·仍走局域网」等占位文案。局域网 Host/Port/指纹仅可作**高级折叠**（默认收起、不引导亲友去填）。
3. **品牌**：窗口标题与产品名用 **「鹊桥」**（或「鹊桥远程协助」），不要「远端协助」。
4. **接受协助（被控）**：第一次点击不得弹「启动被控模式失败」这类异常框；失败须给人话原因 + 可执行下一步（对齐 R003 连不上引导风格）。
5. **实现范围**：`src-net48/` + `scripts/build-net48.ps1` 产物。不改 AI-SSH-Pro；**不新增中继协议字段**（若核实码+密码/载荷经现有 JSONL 已可用则只改 UI/接线；缺字段导致不可用时先回报产品，本轮默认按「协议已够用」实现）。

## 验收标准

1. 冷启动去协助端：首屏主路径是粘贴会话码/载荷 +「连接」；**默认看不到** Host/IP、端口、TLS 指纹输入（若保留，须在折叠「高级 / 局域网」内且默认收起）。
2. 无任何「即将支持·仍走局域网」「中继即将支持」类占位；设置/旁注若出现中继，默认写公网地址或「使用默认中继」，不引导填局域网 IP。
3. 粘贴对方发来的会话码+密码（或 `remoteassist:pair` 载荷），在对方已接受协助时，经**默认公网中继**可配对连上（或按 R003 给出人话失败原因，不得只抛异常框）。
4. 窗口标题/关于/主文案含「鹊桥」，不含「远端协助」作产品名。
5. 接受协助：首次点开始/主按钮，成功则进入展示码+密码；失败为人话+下一步，**不得** MessageBox「启动被控模式失败」+ 堆栈/异常原文当主提示。
6. 交付：`scripts/build-net48.ps1` 可复现产物路径；截图 `docs/screenshots/r043-net48-*`（协助端首屏、粘贴后、被控首屏；勿覆盖 r022–r042）。
7. 未改 AI-SSH-Pro；未改中继 JSONL 字段（除非产品书面同意的最小补字段——本轮默认不改）。
