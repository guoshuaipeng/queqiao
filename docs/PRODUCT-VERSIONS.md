### PV-001 · 官网 /admin 管理客户端会话码

- **状态**：待验收
- **标题**：`http://121.196.45.81/admin` 增加对客户端会话码（code）的管理能力
- **版本**：v0.2
- **说明**：
  - 现有官网管理台（`site/` `/admin`，公网 `http://121.196.45.81/admin`）目前以接单留言为主；需要在此管理台增加对**客户端会话码（code）**的管理。
  - 期望结果：运营在登录 `/admin` 后，能查看（并按合理操作管理）客户端产生的会话码相关记录，例如列表查看、按码查找；具体可管理动作（仅只读查看 / 作废失效码 / 结束会话等）以实现时与用户确认的最小闭环为准。
  - 验收：用管理口令打开公网或等价环境的 `/admin`，能看到会话码管理入口；能列出或查询到客户端 code；敏感字段（密码明文、`password_hash`、完整连接凭证、`fp`、业务载荷）不得展示；与现有接单「新留言 / 已联系 / 已结束」能力不互相破坏。
- **约束**：
  - 入口落在现有 `site/` 管理台（用户指定的 `/admin`），不要另起一套无关后台替代该入口。
  - 会话码数据源在中继侧（`relay` / `relay.db`）；实现时需厘清 site 与 relay 的读管边界（历史 R046 曾约定 site `/admin` 本轮不做会话码读面、中继旁路 HTTP 另开——本需求明确要求挂到 `/admin`，以本条为准，设计时再定对接方式）。
  - 不得削弱被控本机写操作确认；不得在管理台展示或导出密码/完整凭证。
  - 未另说前：本条仅写入队列；上生产/改公网机须对话另行授权。
- **优先级**：高

### PV-002 · 客户端首页与协助端 UI 观感优化

- **状态**：进行中
- **标题**：首页大面积空白难看；协助端按钮折行、输入框过窄，需改好看
- **版本**：v0.2
- **说明**：
  - 首页（模式选择）：当前顶栏 + 两张角色卡偏上，下方大片空白，整体偏丑；需要收紧空白、让卡片更像可点入口、版面更饱满好看。
  - 协助端：连接区/排障区按钮出现折行叠挤；「路径 / 命令参数」等输入框高度过窄；需加高加宽、按钮单行排得开，整体更整齐好看。
  - 验收：首页不再大片空灰；协助端主操作按钮不折行挤压；主要输入框高度够用、观感明显好于现状（对照用户提供截图）。
- **约束**：Windows 主路径 `src-net48`；保持现有蓝/绿品牌与双模式文案，不换框架。**已放行实现**（2026-11-06）；布局/字号等小交互自行拍板。不上公网除非另授权。
- **优先级**：普通

### PV-003 · 打包下载的安装包缺少图标

- **状态**：待验收
- **标题**：官网/分发下载的安装包没有 icon
- **版本**：v0.2
- **说明**：
  - 当前打包供下载的安装包（如 Windows Setup）在资源管理器/下载列表里看不到应用图标（缺 icon）。
  - 期望：安装包本身带品牌图标；装完后开始菜单/桌面快捷方式（若有）也应有图标。
  - 验收：下载安装包后，文件图标可见且为鹊桥品牌图；安装后快捷方式不再是空白/默认 exe 灰标（对照现状截图或本机下载产物）。
- **约束**：优先 Windows 主路径安装包（net48 / Inno 等现有分发）。**已放行实现**（2026-11-06）；图标素材自行选用品牌图。本地出包闭环即可；**不上生产替换下载包**除非另授权。
- **优先级**：普通
