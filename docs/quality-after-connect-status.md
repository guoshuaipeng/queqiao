# 鹊桥 · 质感续篇：连上后状态不要像控制台

> 对照 R039 协助端截图（`r039-avalonia-helper-connected-tools-first-screen.png` 等）。  
> 只改「连上之后」亲友 / 客户支持主路径上的状态文案，不碰 macOS 正式下载、HTTPS、中继协议。  
> 体验主笔；产品 2026-11-06 收口写入仓库。R040（官网包跟上 R039）进行中；本项排在 R040 验收后的下一轮候选，不在此开实现。

## 结论

连上对方电脑后，结果区不要再显示 `PAIR_OK` 这类协议字。改成一句人话状态，并指向「建议先看正在运行的程序」。五键首屏（R039）保持不动。

## 断点

亲友协助方或客户支持已经连上，首屏已有白话五键和「建议先看正在运行的程序，再决定要不要改」。底部结果区却仍写着 `PAIR_OK`，像半成品控制台，和上面的人话打架，刚连上的人会愣一下「是不是出错了」。

## 改法

1. 配对刚成功、尚未点任何操作时，结果区只显示人话，例如：  
   `已连上。建议先点「查看正在运行的程序」。`  
   不要出现 `PAIR_OK`、`paired`、原始 JSON 或协议码。
2. 点了某个常用操作后，结果区再换成该次操作的可读结果（进程列表、文件内容等）；失败时用人话说明，协议原文可放次要行，不能只有原文。
3. 「已连接」按钮禁用态、顶栏「已连接对方电脑」可保留；不改五键文案与顺序，不改粘贴区。

## 验收

- 协助端：从粘贴码连上成功到点第一个操作之前，截图结果区看不到 `PAIR_OK`（或同类协议字），能看到「已连上」且提示先看正在运行的程序。
- 点「查看正在运行的程序」后，结果区是可读列表或人话失败说明，不是裸协议码。
- 本项不改官网下载、macOS 分发、HTTPS、中继或配对协议。

## 不做

- 不重做 R039 五键首屏。
- 不改被协助端发码流程。
- 不另写信任等级文案。
