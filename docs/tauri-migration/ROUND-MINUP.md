# 最小高度下往上翻一行仍是整行

窗口缩到最小高度后，当前结果再往上翻一行，`queqiao-now` 仍是整行。

之前的结果往上翻到长行时，这一行仍是整行，横滑条仍坐在下面。

## 做法

最小高度下一行就是一整行，滚轮按行高往上翻，松手仍停在这一行。这一轮没有改滚动代码，用点击把往上翻测实。

## 验收结果

本机中继 `127.0.0.1:17991`。先在正常高度写出当前结果、展开之前的结果，再把协助窗口的客户区缩到 840×360。当时当前结果停在 `exit=0`（滚动 20），之前的结果也停在 `exit=0`（滚动 120）。然后在各自框里用滚轮向上翻一行。

当前结果翻完滚动是 0，可滚距离是 20。看得见的只有 `queqiao-now`，行高 20，顶 222、底 242，是整行。

之前的结果翻完滚动是 100，可滚距离是 120。看得见的只有那条长行，行高 20，顶 261、底 281，是整行。横滑条占 12。字的墨水到画面 305，横滑条从 312 开始，中间空 7。

协助页多出来的高度是 0，滚动是 hidden，页顶是 0。窗口右侧没有整页竖向滚动条。

图：`acceptance/desktop-minup-before.png` 是翻之前，停在 `exit=0`。`acceptance/desktop-minup-after.png` 是往上翻一行之后。图里没有完整连接凭证。长行横滑到行尾、`QUEEND` 是否在框里，这一轮没有另测。

`npm run check` 51 项通过。`cargo test` 23 项通过。滚动代码沿用上一轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
