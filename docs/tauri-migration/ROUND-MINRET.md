# 最小高度下再翻回长行，QUEEND 还在

窗口缩到最小高度，已经滚回 `exit=0` 且横向还在行尾时，再翻回那条长行。这一行仍是整行，横滑条仍在下面。

`QUEEND` 仍在框里。

## 做法

竖向翻回上一行时，横向位置留在行尾。短行的固定只作用于短行，长行仍停在刚才滑到的地方。这一轮没有改滚动代码，用点击把翻回去测实。

## 验收结果

本机中继 `127.0.0.1:17991`。协助窗口的客户区缩到 840×360。之前的结果先滑到行尾，滚回 `exit=0`（竖向 120），再向上翻回长行。

翻回后竖向是 100，可滚距离是 120。横向是 699，和可滑尽头一致。长行是整行，横滑条占 12。`QUEEND` 在 735–775，在框里。字的墨水到画面 305，横滑条从 312 开始，中间空 7。

协助页多出来的高度是 0，滚动是 hidden，页顶是 0。窗口右侧没有整页竖向滚动条。

图：`acceptance/desktop-minret-before.png` 是翻回之前，停在 `exit=0`。`acceptance/desktop-minret-after.png` 是翻回长行之后。图里没有完整连接凭证。当前结果框里的长行这样横滑，这一轮没有另测。

`npm run check` 51 项通过。`cargo test` 23 项通过。滚动代码沿用上一轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
