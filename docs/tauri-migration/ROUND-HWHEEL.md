# 横向滚轮滑到行尾，整页不动

在之前的结果里用横向滚轮滑到行尾，整页不要跟着上下或左右动。

这样滑到之后，`exit=0` 仍留在左边，`QUEEND` 仍在框里。

## 做法

横向滚轮本来就会改之前的结果自己的横向位置，并拦住整页。这一轮不再直接拨滚动位置，改用真实的横向滚轮。

## 验收结果

本机中继 `127.0.0.1:17991`。协助页先被临时撑开：上下还能滚 357，左右还能滑 1023，并先放在纵向 80、横向 40。

在之前的结果上横向滚三下：旧结果从 0 滑到 718（尽头是 730）。整页纵向仍是 80，横向仍是 40，文档横向仍是 0。`exit=0` 在框内，`QUEEND` 在 684–724，也在框内。

图：`acceptance/desktop-hwheel-before.png`、`desktop-hwheel-after.png`。前一张是整页被临时撑开、还没横滑的样子。后一张已去掉这块撑开。图里没有完整连接凭证。

当前结果框的横向滚轮，这一轮没有另测。横向滚轮停在 718，还没贴到 730。

`npm run check` 49 项通过。`cargo test` 23 项通过。滚动代码沿用前面几轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。

## 下一轮只做这两件

1. 需求：当前结果框也用横向滚轮滑到行尾，整页不要跟着上下或左右动。
2. 小修：再滑一下能贴到可滑尽头，`QUEEND` 不要停在尽头前面一截。
