# 允许留在记录里，展开后能收起

连上之后不要清掉「已允许这次协助」。结束这次协助，上次记录里仍能看到这句。

记录展开后，按钮改成「收起」。再点一次，记录合上，按钮回到「查看上次协助记录」。

## 验收结果

本机中继 `127.0.0.1:17991`。连上后被协助端立刻能看到「已允许这次协助」。结束协助后展开记录，这句还在，按钮是「收起」。再点一次，记录不再显示，按钮回到「查看上次协助记录」。
