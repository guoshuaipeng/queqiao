# 最小高度下末行是整行，横滑条在字下面

窗口缩到最小高度后，当前结果里的 `exit=0` 仍是整行。

之前的结果里看得见的那一行也是整行，横滑条坐在这行下面。

## 做法

客户区高度到 400 以下时，结果框按整行来定高：一行 20，边框 2，有横滑才再加 12。不再多留一截，免得露出半行。当前结果本来跟着最后一行时，缩完仍停在最后一行。

## 验收结果

本机中继 `127.0.0.1:17991`。先在正常高度写出当前结果、展开之前的结果，再把协助窗口的客户区缩到 840×360。

当前结果框高 22，没有横滑条。滚动停在 20。看得见的只有 `exit=0`，行高 20，顶 222、底 242，整行都在框里。上面没有半行。

之前的结果框高 34，横滑条占 12。滚动停在 120。看得见的只有 `exit=0`，行高 20，顶 261、底 281，整行都在横滑条上面。字的墨水到画面 305，横滑条从 312 开始，中间空 7。窗口右侧没有整页竖向滚动条。协助页多出来的高度是 0，滚动是 hidden。「要做什么」和「结束本次协助」仍在窗口里。
