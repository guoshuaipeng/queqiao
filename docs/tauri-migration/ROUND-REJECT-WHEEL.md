# 拒绝一次连接，以及窄窗口滚轮

对方连上后弹出「有人想协助这台电脑」，默认在「拒绝」。点「拒绝」不进会话页，仍停在等待，保留「复制连接凭证」。协助端回到首页，显示「对方没有同意这次协助。」，不出现「正在协助对方 · 已连接」。

窄于 760 时首页只有一层可滚。滚轮记到这一层，把「连接」滚进客户区。外层不再同时打开滚动，避免滚轮停在滚不动的父层上。

## 验收结果

本机中继 `127.0.0.1:17991`。点「开启接受协助」后是等待，密码是圆点。另一扇窗口用凭证连接后，出现「有人想协助这台电脑」。点「拒绝」后弹窗消失，仍有「等待对方连接」和「复制连接凭证」，没有「正在接受协助 · 已连接」。协助端显示「对方没有同意这次协助。」，没有「正在协助对方 · 已连接」。图：`acceptance/desktop-before-reject.png`、`desktop-after-reject-helper.png`。被协助端拒绝后的整窗含复制失败留下的原文，没有保存。

客户区 640×360 时，「连接」先在客户区下方。滚轮后按钮进入客户区。图：`acceptance/desktop-narrow-before-wheel.png`、`desktop-narrow-after-wheel.png`。当时锁屏盖住桌面，物理鼠标到不了窗口；送进窗口的滚轮事件完成了这次滚动。

`npm run check` 8 项通过。`cargo test` 17 项通过。发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
