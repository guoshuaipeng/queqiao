# 确认超时不执行，结果先看正文

确认时间走完且没有点「允许」，这项改动不执行。倒计时到 0 不再替用户点「拒绝」，由服务端记成超时。双方都看到「确认超时，未做任何改动」。

允许之后的结果先写输出正文，exit 放在后面，不再用 stdout 分隔线开头。

## 验收结果

本机中继 `127.0.0.1:17991`。提议改动后不点按钮，等满确认时间。被协助端是「已拒绝：确认超时，未做任何改动」。协助端是「确认超时，未做任何改动」，命令框已空。标记文件没有生成。

再提议一次并点「允许」。协助端结果第一行是输出正文，下一行才是 exit，没有分隔线。

图：`acceptance/desktop-timeout-dialog.png`、`desktop-timeout-host.png`、`desktop-timeout-helper.png`、`desktop-result-body.png`。

`npm run check` 13 项通过。`cargo test` 20 项通过。发布构建后做了上述点击，超时按 60 秒等完。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
