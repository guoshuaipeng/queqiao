# 翻回最底下，行尾还在，末行是整行

当前结果翻到第一行后再滚回最底下，横向仍停在行尾，竖向回到最底下。

滚回后 `exit=0` 是整行，`QUEEND` 在框里。

## 做法

松手时如果离最底下不到一行，就回到真正的最底下，不停在上一整行把末行留在下面。横向位置仍按记下的行尾拨回去。

## 验收结果

本机中继 `127.0.0.1:17991`。当前结果先在最底 76，横向滚轮滑到行尾，再翻到第一行。向下滚回后，把滚动放在尽头前 6，再松手。

改之前：松手后竖向是 76，和最底下一致。横向 715，和可滑尽头一致。`exit=0` 是整行。`QUEEND` 在 727–767，在框里。

改之后再测，数字相同。

图：`acceptance/desktop-back-old-before.png`、`desktop-back-old.png`、`desktop-back-before.png`、`desktop-back-after.png`。带 old 的是改之前。前一张是翻到第一行、还没滚回去的样子。图里没有完整连接凭证。

之前的结果这样滚回，这一轮没有另测。
