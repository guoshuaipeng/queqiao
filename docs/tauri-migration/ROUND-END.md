# 点开旧结果停在末行，长行躲开竖滑条

点开之前的结果后停在最新两行，能看见 `exit=0`。

长行右边不要贴着竖滑条，留出先前那样的空隙。

## 做法

框被收矮之后再滚到末行。先前在收矮之前就对齐，内容还放得下，滚动停在 0，收成两行后仍停在第一行。

竖滑条左边加一条 24px 的空白，字画到这条为止。行尾的内边距加到 36px，横滑到头时行尾仍在这条左边。

## 验收结果

本机中继 `127.0.0.1:17991`。

改之前：点开后滚动停在 0，眼前是 `queqiao-line-1` 和 `queqiao-line-2`，没有 `exit=0`。长行的行框一直伸到结果框右沿，空隙是 0。

改之后：点开后滚动停在最底（36，已到头）。眼前是长行和 `exit=0`，没有 `queqiao-line-1`。`exit=0` 的字在横滑条上面。长行右边到结果框右沿 39。横滑到头后，行尾 `QUEEND` 仍在这条空白的左边。

图：`acceptance/desktop-end-before-past.png`、`desktop-end-after.png`、`desktop-gap-after.png`、`desktop-end-tail.png`。图里没有完整连接凭证。

横滑到行尾时，短行 `exit=0` 会跟着滑出左边。点开之后再往上翻能不能看到第一行，这一轮没有另测。
