# 结束这次协助，以及取消后的那一句

已连接后点「结束本次协助」，先确认「结束协助」。确认后关掉套接字并回到首页。对方发现连接断了，也回到首页，并写上「对方已结束这次协助。」旧凭证再连不会进入这次会话。

协助端在对方还没允许时点「取消」，右侧显示「已取消，没有连上。」

## 验收结果

本机中继 `127.0.0.1:17991`。双方都出现已连接。被协助端确认结束后回到「开启接受协助」，没有已连接。协助端显示「对方已结束这次协助。」，没有已连接。同一份凭证再连：没有「有人想协助这台电脑」，没有已连接，协助端是「没能连上，请检查网络后重试。」

取消后协助端出现「已取消，没有连上。」
