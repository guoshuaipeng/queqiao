# 翻回最底下后整页没有竖条

这样翻回最底下之后，协助页在正常高度下不要多出一条竖向滚动条。

「要做什么」和「结束本次协助」仍完整留在窗口里。

## 做法

协助页超出不到 4 时不显示竖向滚动条。翻回最底下只动之前的结果自己的滚动，不把整页撑高。这一轮没有改布局代码，用点击把正常高度测实。

## 验收结果

本机中继 `127.0.0.1:17991`。窗口高 480。之前的结果翻到第一行后再滚回最底下，没有临时把整页撑高。

协助页多出来的高度是 4，滚动是 hidden，页顶停在 0。窗口右侧没有整页竖向滚动条。

「要做什么」高 38，顶在 131，底在 169，贴在常用操作那一排下面，左右在 24–816。「结束本次协助」高 38，顶在 430，底在 468，落在窗口里。

图：`acceptance/desktop-fitback-after.png`。图里没有完整连接凭证。窗口缩到最小高度时，这两处有没有被切掉，这一轮没有另测。

`npm run check` 50 项通过。`cargo test` 23 项通过。布局代码沿用前面几轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
