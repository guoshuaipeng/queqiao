# 结果框长行躲开滚动条，顶底滚轮不带动整页

当前结果框的长行不要被它自己的滚动条挡住。

结果框已经到顶或到底时，继续滚轮不要带动整页。

## 验收结果

本机中继 `127.0.0.1:17991`。长行右沿距结果框右边 36，字停在滚动条左边。到底时结果停在 1140，再向下滚，整页仍是 1。到顶后再向上滚，结果仍是 0，整页仍是 1，眼前是 `queqiao-line-1`。

图：`acceptance/desktop-result-gutter.png`、`desktop-edge-after.png`。

`npm run check` 38 项通过。`cargo test` 23 项通过。发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。

## 下一轮只做这两件

1. 需求：长行可以横着滑，能看到行尾。
2. 小修：横滑时不要把整页左右带动。
