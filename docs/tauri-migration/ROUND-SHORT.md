# 短结果滚轮不带动整页，行尾旁的短行留着

当前结果只有几行、框自己滚不动时，在框里滚轮，整页不要跟着动。

这种短输出里有一行很长时，滑到行尾后 `exit=0` 仍留在左边。

## 做法

滚轮落在当前结果上时，框自己没有竖向可滚的距离，也不把滚动交给整页。短行按横向位置留在左边。这段拦截上一轮已经写上，这一轮用点击把「只有几行」测实。

## 验收结果

本机中继 `127.0.0.1:17991`。协助页先被临时撑高，上面还能滚 80，下面还能滚 257。当前结果竖向可滚距离是 0，横向可滑 730。

在结果框里向上、向下各滚一下：整页仍是 80，结果仍是 0。

再滑到行尾：横向 718，整页仍是 80。`exit=0` 在 37–77，`QUEEND` 在 724–764，都在框里。
