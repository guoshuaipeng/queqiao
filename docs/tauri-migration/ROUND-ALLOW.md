# 点允许才执行，拒绝后清掉命令

被协助端点「允许」之后才执行这项改动。结果回到协助端。点「拒绝」则不执行，并清掉协助端刚才填写的说明和命令，避免下一次误发出去。

## 验收结果

本机中继 `127.0.0.1:17991`。双方已连接。提议改动后点「允许」：协助端看到输出和「已完成」，被协助端记录「已允许：回显一句」，标记文件已生成。

再提议一条并点「拒绝」：「要做什么」和「命令」都空，结果是「已拒绝，未做任何改动」，第二条标记文件没有生成。
