# 最小高度下往上翻再滚回，行尾还在

窗口缩到最小高度，当前结果的长行已经在行尾。再往上翻一行，看得见的行仍是整行，横滑条仍在下面。

再滚回最底下时，`QUEEND` 仍在框里，横向仍停在行尾。

## 做法

竖向翻页不改横向位置。短的行固定在左边，长行留在刚才滑到的地方。这一轮没有改滚动代码，用点击把往上翻和滚回去测实。

往上翻之后竖向是 60。看得见三行，都是整行：`queqiao-line-4` 在 222–242，`queqiao-line-5` 在 242–262，长行在 262–282。横滑条占 12。横向仍是 699。长行的墨水到画面 306，横滑条从 313 开始，中间空 7。

滚回最底下后竖向是 80，就是最底。横向是 699，和可滑尽头一致。长行仍是整行。`QUEEND` 在 735–775，在框里。横滑条占 12。协助页多出来的高度是 0，滚动是 hidden，页顶是 0。窗口右侧没有整页竖向滚动条。
