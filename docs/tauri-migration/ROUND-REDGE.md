# 当前结果到顶到底不带动整页，翻回来行尾还在

当前结果框已经到顶或到底时，继续滚，整页不要跟着动。

当前结果滑到行尾后，上下翻再回来，行尾还在，`exit=0` 仍留在左边。

## 做法

当前结果的滚轮和之前的结果一样：已经到顶或到底，也不把滚动交给整页。横向位置记下来，竖着翻如果把它清掉，再拨回去。
