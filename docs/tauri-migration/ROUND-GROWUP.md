# 拉回正常高度后往上翻再滚回

拉回正常高度后，再往上翻一行。看得见的行仍是整行，横滑条仍在下面。

再滚回最底下时，`QUEEND` 仍在框里，横向仍停在行尾。

## 做法

竖向翻页不改横向位置。拉高后结果框按整行来高，所以往上翻一行仍停在整行上。这一轮没有改滚动代码，用点击把往上翻和滚回去测实。

## 验收结果

本机中继 `127.0.0.1:17991`。只写出这一次长结果。先缩到客户区 840×360，横滑到行尾，再拉回客户区高 480。当时竖向是 60、横向是 715。然后向上翻一行，再滚回最底下。

往上翻之后竖向是 40。看得见四行，都是整行：`queqiao-line-3` 在 304–324，`queqiao-line-4` 在 324–344，`queqiao-line-5` 在 344–364，长行在 364–384。横滑条占 12。横向仍是 715。长行的墨水到画面 408，横滑条从 415 开始，中间空 7。

滚回最底下后竖向是 60，就是最底。横向是 715，和可滑尽头一致。长行仍是整行。`QUEEND` 在 727–767，在框里。窗口右侧没有整页竖向滚动条。
