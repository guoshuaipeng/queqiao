# 拉回后再滚回最底下，整页不动

拉回正常高度、已经往上翻一行后，再滚回最底下时，滚轮也不要带动整页。

`QUEEND` 仍在框里，横向仍停在行尾。

## 做法

结果框里的滚轮只翻这一框。整页先被撑开，证明它本来还能上下左右动。这一轮没有改滚动代码，用点击把滚回去这一下测实。

## 验收结果

本机中继 `127.0.0.1:17991`。只写出这一次长结果。先缩到客户区 840×360，横滑到行尾，拉回客户区高 480，再向上翻一行。结果框竖向停在 40，横向是 715。

滚回去的时候临时把协助页撑开：纵向放在 40，横向放在 40，下面还能滚 359，左右还能滑 1023。滚回最底下后，纵向仍是 40，横向仍是 40，文档横向仍是 0。结果框的竖向回到 60，就是最底。

这时长行仍是整行，还看得见。`QUEEND` 在 687–727，在框里。横向仍是 715。撤掉临时撑高后，横向是 715，和可滑尽头一致。`QUEEND` 在 727–767，在框里。长行右侧的墨水到画面 388，横滑条从 415 开始，中间空 27。窗口右侧没有整页竖向滚动条。
