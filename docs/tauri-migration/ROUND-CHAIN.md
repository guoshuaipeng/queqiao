# 到顶后整页不动，滚回时行尾还在

在之前的结果里已经到第一行时，继续向上滚，整页不要跟着动。

再滚回最底下时，长行仍停在刚才的行尾，`exit=0` 仍留在左边。

## 做法

滚轮落在之前的结果上时，就算已经到顶、不能再翻，也不把滚动交给整页。

横向滑过的位置记下来。竖着翻如果把这个位置清掉，再拨回去。短行仍按这个位置留在左边。

## 验收结果

本机中继 `127.0.0.1:17991`。协助页先被临时撑高，确认它自己还能往上滚 341，并先放在 200。

改之前的构建：在第一行上再向上滚两下，整页仍是 200，之前的结果仍是 0，横向仍是 715，第一行是整行。再向下滚回最底（36，已到头），横向仍是 715，`exit=0` 在 37–77，`QUEEND` 在 727–767。

改之后再测，数字相同。向下滚回时整页仍是 200，没有被带着走。

图：`acceptance/desktop-chain-before.png`、`desktop-chain-after.png`、`desktop-chain-tail-before.png`、`desktop-chain-tail.png`。前两张为了让整页能够滚动，临时加了底部空白，所以窗口里能看到整页滚动条。后一张已去掉这块空白。图里没有完整连接凭证。

当前结果框到顶后继续向上滚，这一轮没有另测。

`npm run check` 45 项通过。`cargo test` 23 项通过。发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
