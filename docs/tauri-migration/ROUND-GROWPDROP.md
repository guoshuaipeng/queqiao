# 之前的结果里再向下滚，整页不动

在之前的结果里再向下滚一下。不要带动整页，也不带动当前结果。

看得见的两行仍留在左边，都是整行，下面没有横滑条。

## 做法

之前的结果只有两行短字，自己滚不动。向上滚过之后，再向下滚一下。整页先被撑开，证明它本来还能上下左右动。滚轮打在之前的结果上。这一轮没有改滚动代码，用点击把这一下测实。

## 验收结果

本机中继 `127.0.0.1:17991`。先写一句 `queqiao-old-line`，再写出长结果。缩到客户区 840×360，横滑到行尾，拉回 480，点开之前的结果，把当前结果滚回最底下，在之前的结果里先向上滚一行，再向下滚一下。

向下滚的时候临时把协助页撑开：纵向放在 40，横向放在 40，下面还能滚 357，左右还能滑 1023。滚完后纵向仍是 40，横向仍是 40，文档横向仍是 0。当前结果竖向仍是 100，横向仍是 715。之前的结果竖向仍是 0。

撤掉临时撑高后，两行都留在左边，都是整行。`queqiao-old-line` 字从 37 到 143，行高 20，在 375–395。`exit=0` 字从 37 到 77，行高 20，在 395–415。框左是 24。横滑条占 2，只是边框。

墨水分别到画面 419 和 439，都从 47 开始。下面没有横滑条。多出来的高度是 0，滚动是 hidden，页顶是 0。窗口右侧没有整页竖向滚动条。
