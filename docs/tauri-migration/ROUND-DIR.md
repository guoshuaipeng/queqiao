# 查看文件夹不询问，程序名能看懂

查看文件夹和查看正在运行的程序都属于查看，不弹确认。文件夹填好路径点查看后，结果直接回来。程序名单只留程序名；同一个程序有多个时，在名字后面写个数。

## 验收结果

本机中继 `127.0.0.1:17991`。填好一个临时文件夹的路径后点「查看」，没有「对方想在这台电脑执行操作」，结果里有那个文件名。再点「查看正在运行的程序」，结果是 `svchost.exe` 这种名字，并带个数，没有原始表格。

图：`acceptance/desktop-dir-result.png`、`desktop-proc-names.png`。

`npm run check` 14 项通过。`cargo test` 21 项通过。发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
