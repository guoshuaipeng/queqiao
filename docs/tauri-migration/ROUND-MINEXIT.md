# 最小高度下滚回后 exit=0 留在左边

窗口缩到最小高度，滚回最底下后，`exit=0` 仍留在左边，这一行仍是整行。

横滑条仍坐在这行下面。

## 做法

短行跟着横向滚动平移，所以滚到行尾时 `exit=0` 还在左边。横滑条占结果框底部的 12，不压进这一行。这一轮没有改滚动代码，用点击把滚回最底下之后的这一行测实。

## 验收结果

本机中继 `127.0.0.1:17991`。只写出这一次长结果。协助窗口的客户区缩到 840×360。当前结果先横滑到行尾，向上翻一行，再滚回最底下。

滚回后竖向是 80，就是最底。横向是 699，和可滑尽头一致。`exit=0` 行高 20，顶 262、底 282，是整行，也是看得见的最下面一行。字的左边在 29，框的左边在 16，右边在 69。横滑条占 12。字的墨水到画面 306，横滑条从 313 开始，中间空 7。

协助页多出来的高度是 0，滚动是 hidden，页顶是 0。窗口右侧没有整页竖向滚动条。

图：`acceptance/desktop-minexit-before.png` 是往上翻一行之后，还没滚回。`acceptance/desktop-minexit-after.png` 是滚回最底下之后。图里没有完整连接凭证。从最小高度拉回正常高度后这一行还在不在，这一轮没有另测。

`npm run check` 51 项通过。`cargo test` 23 项通过。滚动代码沿用上一轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
