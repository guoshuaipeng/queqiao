# 查看文件不询问，文件夹用中文

查看文件和查看文件夹都不弹确认。文件填好路径点查看后，正文直接回来。文件夹里的条目写成「文件」或「文件夹」，不再写 FILE / DIR。

## 验收结果

本机中继 `127.0.0.1:17991`。点「查看文件」并填好路径后点「查看」，没有「对方想在这台电脑执行操作」，结果是文件正文。再查看同一个文件夹，结果是「文件」和「文件夹」。

图：`acceptance/desktop-file-before.png`、`desktop-file-after.png`、`desktop-dir-kinds.png`。

`npm run check` 14 项通过。`cargo test` 22 项通过。发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
