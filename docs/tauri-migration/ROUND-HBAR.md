# 横滑条坐在文字下面

之前的结果出现横滑条时，两行文字仍完整，不要被横滑条切掉。

当前结果框的横滑条也不要盖住最下面一行。

## 做法

横滑条改成占位置的 12px 条，不再画在最后一行上面。结果框和之前的结果都留出这条的高度。
