# 最小高度下滚回 exit=0，行尾还在

窗口缩到最小高度，长行已经在行尾时，再滚回 `exit=0`。这一行仍是整行，横滑条仍在下面。

`exit=0` 仍留在左边，横向仍停在行尾。

## 做法

短行跟着横向滚动平移，所以滚回末行时字还在左边。横向位置记在这一框上，竖向翻页不把它清掉。这一轮没有改滚动代码，用点击把滚回去测实。

## 验收结果

本机中继 `127.0.0.1:17991`。协助窗口的客户区缩到 840×360。之前的结果先向上翻到长行（滚动 100），再横滑到行尾，然后向下滚回 `exit=0`。

滚回后竖向是 120，就是最底下。横向是 699，和可滑尽头一致。`exit=0` 行高 20，顶 261、底 281，是整行。字的左边在 29，框的左边在 16。横滑条占 12。字的墨水到画面 305，横滑条从 312 开始，中间空 7。

协助页多出来的高度是 0，滚动是 hidden，页顶是 0。窗口右侧没有整页竖向滚动条。

图：`acceptance/desktop-minback-before.png` 是滚回之前，长行停在行尾。`acceptance/desktop-minback-after.png` 是滚回 `exit=0` 之后。图里没有完整连接凭证。再翻回长行时 `QUEEND` 还在不在框里，这一轮没有另测。

`npm run check` 51 项通过。`cargo test` 23 项通过。滚动代码沿用上一轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
