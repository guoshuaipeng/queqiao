# 开启失败与复制

中继端口没人听时，点「开启接受协助」停在首页。文案是「没能开启接受协助，请检查网络后重试。」主按钮变成「重试开启」。不出现会话码，不进入会话页。

「复制连接凭证」先由窗口自己打开剪贴板写入。成功只提示「已复制，请完整发给对方。」失败提示「没能复制，请再点一次。」并让原文框获得焦点。两种结果都不把凭证写进日志。

## 验收结果

对 `127.0.0.1:9` 点开启后，桌面窗口出现上述失败文案和「重试开启」。没有「等待对方连接」，没有「复制连接凭证」，没有「正在接受协助 · 已连接」。图：`acceptance/desktop-open-fail.png`。

点「复制连接凭证」后是失败文案，原文框获焦，没有成功提示。本机 `OpenClipboard` 返回错误 5，空句柄和窗口句柄都一样，经资源管理器启动的进程也一样。不能说剪贴板里已经有凭证。

不是两台电脑，也不是生产中继。含测试凭证的图已删除。

## 下一轮只做这两件

1. 需求：等待中点「停止接受」，回到空闲，不留下可进入的会话。
2. 小修：在系统允许打开剪贴板时，让复制成功写入。本机错误 5 还没解开。
