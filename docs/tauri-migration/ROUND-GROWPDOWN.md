# 点开后再滚回最底，整页不动

点开之前的结果、当前结果已经往上翻一行后，再滚回最底下。滚轮不要带动整页。

`QUEEND` 仍在框里，看得见的行仍是整行，横滑条仍在下面。

## 做法

结果框里的滚轮只翻这一框。整页先被撑开，证明它本来还能上下左右动。往上翻一行之后，仍在撑开的状态下滚回最底下。这一轮没有改滚动代码，用点击把这一下测实。

## 验收结果

本机中继 `127.0.0.1:17991`。先写一句 `queqiao-old-line`，再写出长结果。缩到客户区 840×360，横滑到行尾，拉回 480，向上翻一行，滚回最底下，点开之前的结果，再把当前结果向上翻一行。这时竖向停在 80，横向是 715。

滚回时临时把协助页撑开：纵向放在 40，横向放在 40，下面还能滚 357，左右还能滑 1023。向下滚回一行后，纵向仍是 40，横向仍是 40，文档横向仍是 0。结果框的竖向从 80 回到 100，和可滚尽头一致。横向仍是 715。

看得见两行，都是整行：长行在 256–276，`exit=0` 在 276–296。横滑条占 12。`QUEEND` 在 687–727，在框里。撤掉临时撑高后，`exit=0` 的墨水到画面 360，横滑条从 367 开始，中间空 7。长行右侧的墨水到画面 340，和横滑条中间空 27。窗口右侧没有整页竖向滚动条。
