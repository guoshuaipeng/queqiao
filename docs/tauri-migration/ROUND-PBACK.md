# 旧结果滚回最底下，行尾还在，末行是整行

之前的结果翻到第一行后再滚回最底下，横向仍停在行尾，竖向回到最底下。

滚回后 `exit=0` 是整行，`QUEEND` 在框里。

## 做法

离最底下不到一行就回到真正的最底下，这条上一轮已经写在共用的松手对齐里。之前的结果松手时走的就是它。这一轮用点击把旧结果测实，没有再改滚动代码。

## 验收结果

本机中继 `127.0.0.1:17991`。之前的结果先在最底 96，横向滚轮滑到行尾，再翻到第一行。向下滚回后，把滚动放在尽头前 6，再松手。

松手后竖向是 96，就是最底下。横向 715，和可滑尽头一致。`exit=0` 是整行。`QUEEND` 在 727–767，在框里。

图：`acceptance/desktop-pback-before.png`、`desktop-pback-after.png`。前一张是翻到第一行的样子。后一张是滚回最底下的样子。图里没有完整连接凭证。

这样滚的时候整页会不会多出竖向滚动条，这一轮没有另测。

`npm run check` 50 项通过。`cargo test` 23 项通过。滚动代码沿用上一轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
