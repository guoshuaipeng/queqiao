# 当前结果横向滚轮贴到尽头，整页不动

当前结果框也用横向滚轮滑到行尾，整页不要跟着上下或左右动。

再滑一下能贴到可滑尽头，`QUEEND` 不要停在尽头前面一截。

## 做法

滚到头时直接拨到内容的尽头，由浏览器停在它真正允许的位置。

滚动条已经占了 12px，不再另外留一条滚动条槽。上一轮报的尽头 730，比滚轮能到达的 718 多了这 12。去掉之后，报出来的尽头和滚轮停下的位置是同一个数。

## 验收结果

本机中继 `127.0.0.1:17991`。协助页先被临时撑开，上下还能滚 363，左右还能滑 1023，并先放在纵向 80、横向 40。

改之前：横向滚轮停在 718，再往前拨也还是 718。当时算出来的尽头是 730。

改之后：当前结果用横向滚轮从 0 滑到 718。算出来的尽头也是 718，再拨到内容尽头仍是 718。整页纵向仍是 80，横向仍是 40，文档横向仍是 0。`QUEEND` 在 684–724，在框里。`exit=0` 也在框里。

图：`acceptance/desktop-rwheel-old-before.png`、`desktop-rwheel-old.png`、`desktop-rwheel-before.png`、`desktop-rwheel-after.png`。带 old 的是改之前。前一张整页被临时撑开。图里没有完整连接凭证。
