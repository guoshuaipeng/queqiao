# 最小高度下长行滑到行尾，整页不动

窗口缩到最小高度后，把之前的结果里这条长行横滑到行尾。这一行仍是整行，横滑条仍在下面。

这样滑完 `QUEEND` 仍在框里，整页不要跟着动。

## 做法

横滑只动这一框自己的横向位置，竖向留在长行上。滑过尽头时停在浏览器允许的那一格。这一轮没有改滚动代码，用点击把最小高度下的横滑测实。

## 验收结果

本机中继 `127.0.0.1:17991`。先把协助窗口的客户区缩到 840×360，再在之前的结果里向上翻一行，停在长行（滚动 100）。然后用横向滚轮滑到行尾。

为了证明整页真的能被带动，滑的时候临时把协助页撑开：纵向放在 40，横向放在 40，下面还能滚 253，左右还能滑 1007。滑完纵向仍是 40、横向仍是 40，文档横向仍是 0。竖向仍是 100。

横向停在 714，和可滑尽头一致。长行仍是整行，横滑条占 12。`QUEEND` 在 680–720，在框里。

滑完后撤掉临时撑高。字的墨水到画面 305，横滑条从 312 开始，中间空 7。窗口右侧没有整页竖向滚动条。

图：`acceptance/desktop-minslide-before.png` 是横滑之前，长行停在开头。`acceptance/desktop-minslide-after.png` 是滑到行尾、撤掉临时撑高之后。图里没有完整连接凭证。再滚回 `exit=0` 时行尾还在不在，这一轮没有另测。

`npm run check` 51 项通过。`cargo test` 23 项通过。滚动代码沿用上一轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
