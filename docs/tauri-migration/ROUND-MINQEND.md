# 拉回正常高度后 QUEEND 还在框里

从最小高度拉回正常高度后，长行的 `QUEEND` 仍在框里。

横滑条不压住这一行。

## 做法

拉高后如果原来已经在行尾，横向补到新的尽头，长行仍整行留在横滑条上面。这一轮没有改滚动代码，用点击把 `QUEEND` 和横滑条的位置测实。

## 验收结果

本机中继 `127.0.0.1:17991`。只写出这一次长结果。先把协助窗口缩到客户区 840×360，横滑到行尾，再拉回客户区高 480。

拉回后窗口高 480。竖向是 60，就是最底。横向是 715，和可滑尽头一致。长行是整行，看得见的行都是整行。横滑条占 12。`QUEEND` 在 727–767，顶 347、底 361，在框里，也躲开了这一框自己的竖向滚动条。

长行右侧的墨水到画面 388，横滑条从 415 开始，中间空 27。横滑条没有压住这一行。协助页多出来的高度是 2，滚动是 hidden，页顶是 0。窗口右侧没有整页竖向滚动条。

图：`acceptance/desktop-minqend-before.png` 是拉高之前。`acceptance/desktop-minqend-after.png` 是拉回正常高度之后。图里没有完整连接凭证。拉回后再往上翻一行，这一轮没有另测。
