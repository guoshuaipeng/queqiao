# 横滑后再翻到第一行，行尾还在

之前的结果在最底下横滑到行尾后，再往上翻到第一行，横向仍停在行尾，`exit=0` 仍留在左边。

松手后第一行是整行，不要被切成半行。

## 做法

松手对齐时如果已经在最底下，就留在最底下。对齐到某一行时，横向位置按记下的行尾拨回去，短行仍留在左边。
