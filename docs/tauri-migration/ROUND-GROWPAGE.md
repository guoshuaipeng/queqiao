# 拉回后往上翻，整页不动

拉回正常高度后往上翻一行时，滚轮不要带动整页。

这时长行的 `QUEEND` 仍在框里。

## 做法

结果框里的滚轮只翻这一框。整页先被撑开，证明它本来还能上下左右动。这一轮没有改滚动代码，用点击把这一下测实。

## 验收结果

本机中继 `127.0.0.1:17991`。只写出这一次长结果。先缩到客户区 840×360，横滑到行尾，再拉回客户区高 480。竖向停在最底 60，横向是 715。

为了证明整页真的能被带动，翻的时候临时把协助页撑开：纵向放在 40，横向放在 40，下面还能滚 359，左右还能滑 1023。向上翻一行之后，纵向仍是 40，横向仍是 40，文档横向仍是 0。结果框的竖向从 60 到 40。

这时长行仍是整行，还看得见。`QUEEND` 在 687–727，在框里。横向仍是 715。撤掉临时撑高后，长行的墨水到画面 408，横滑条从 415 开始，中间空 7。窗口右侧没有整页竖向滚动条。

图：`acceptance/desktop-growpage-before.png` 是翻之前，停在最底下。`acceptance/desktop-growpage-after.png` 是往上翻一行、撤掉临时撑高之后。图里没有完整连接凭证。再滚回最底下时整页会不会跟着动，这一轮没有另测。

`npm run check` 51 项通过。`cargo test` 23 项通过。滚动代码沿用上一轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
