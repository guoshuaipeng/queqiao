# 完全信任只在这次，确认框写出命令

完全信任只对当前这次协助生效。点「结束完全信任」后，下一次改动重新弹确认，拒绝就不执行。

改动确认框直接显示要执行的命令，不再收在「查看详细」里。

本机中继 `127.0.0.1:17991`。打开完全信任后，横幅出现。`echo queqiao-full-ran` 没有确认弹窗，结果回来，标记文件生成，记下「已执行」。点「结束完全信任」后横幅消失。再发一条改动，确认框出现，框里直接是命令原文，没有「查看详细」。点「拒绝」后没有生成第二个文件。
