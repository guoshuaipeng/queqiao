- 在主仓**专用分支**上开展 **Tauri 迁移开发**（Windows 首批：壳 + Rust 原生系统命令/截屏/注入/剪贴板等）。

- 架构 / 迭代 / 客户端（新栈）按分工推进；**分支名与创建回执以实际为准**，本文不预填假分支。  
- 权限 / UAC / sidecar 生命周期测试（隔离环境；不读用户真实凭证；不关用户正在用的程序除非另授）。

- **旧 .NET / net48 功能开发仍冻结**（15:05）；不得用本授权给 net48 功能迭代开绿灯。  
- **禁止**降级短码、静默失败、削弱完整凭证 / 配对 / 信任档。  
- **R050 与凭证安全不解除**。  
- **无生产发布授权**；官网既有发布授权**不扩至**客户端。  
- **旧 .NET 删除**：仅「迁移做完并验收之后」；**未验收不得删除**。  
- 不混入官网静态发布批次；不偷带无关脏树。
