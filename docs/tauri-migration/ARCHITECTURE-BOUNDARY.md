| 允许 | 禁止 |

| 主仓**专用迁移分支**上的 Tauri 客户端 | 2026-11-09 用户已要求删除 .NET 客户端；不要把已删除的 net48/net8 加回来 |

## 2. 分支基点与隔离（强制）

| 项 | 规定 |
|----|------|
| 建议分支名 | `feat/tauri-client-migration` |
| 基点 | 远端/本地 **干净** 的当前主线 tip（`master`/`main` 以仓为准）；**禁止**从带未提交脏改、官网 ahead 混合树、或未提交 A-net48 实现的工作树直接切出 |
| 唯一建分支人 | **鹊桥-迭代**（一人执行 `fetch` → 确认 clean → `checkout -b` → push `-u`）；回报：基点 SHA、新分支 tip SHA、远端是否已跟踪 |
| 工作树隔离 | **鹊桥-客户端** 使用**独立 worktree 或干净检出**只跟踪该分支；迭代不在同一脏目录并行写客户端；服务端/官网继续各自树，**禁止**多人 `checkout` 抢同一工作目录 |
| 旧栈 | 2026-11-09 已按用户要求删除。不要恢复 |

## 3. 架构边界（协议 / 会话）

1. **凭证**：复制/粘贴载荷 = 现行完整 `remoteassist:pair`（含 Agent `fp=`）；禁 short-code-only；本地校验先于联网。  
2. **中继**：沿用现有 JSONL relay 与 TLS pin；Tauri 侧为新客户端实现，不顺带改 relay 行为除非另授服务端范围。  
3. **会话态**：Idle → 开启中 → Waiting（入口双区，已监听）→ Connected（业务会话页）；Waiting ≠ Connected；停止接受 / 结束均须清理成功才回 Idle；迟到成功不进会话。  
4. **单活动角色**：与 A 细则互斥确认框一致；Disable ≠ 取消。  
5. **信任/配对**：不改本机信任档与配对确认语义；不主推账号免密。  
6. **R050**：保持 blocked；迁栈不解锁 PAKE 实现。

## 4. 首批可交付范围（Windows）

**D0 · 仓与壳（本周可验收文档+空壳）**

- 分支存在且可跟踪；`apps/queqiao-tauri/`（或仓内约定路径）Tauri v2 空壳可在 Windows 本地 `dev` 启动。  
- 本文件与探针验收清单落入仓内 `docs/tauri-migration/`（由迭代落盘）。

**D1 · 能力地板（并入迁移验收，非完成定义）**

- Shell 白名单、截屏单帧、剪贴板长文本、基础键鼠注入（他进程焦点）——对齐探针门槛；失败可观测。

**D2 · 协议地板**

- 解析/校验完整 pair+fp；显式点击后才连 relay；能完成与现网（或获准试验中继）的 Waiting→业务通道最小闭环（协助或被控先打通一侧也可，但须书面声明）。

**D3 · 生命周期地板**

- 显式开启/停止接受；取消与世代；结束清理成功→Idle；外框/窗尺寸策略按 A（切态不自动乱改）。

**明确不在首批**：删 .NET；Mac/Linux 协助对等；R050；无人值守；官网；生产推送客户端安装包。

## 5. 完成定义（迁移「主路径打通」≠ 删旧）

须同时满足才可向产品申请「条件授权删旧 .NET」评审：

- Windows 被控+协助主路径真 UI 验收通过（含 Waiting≠Connected、停止/结束清理）。  
- 安全回归：完整 pair、禁短码、TLS pin、无明文旁路。  
- 能力地板 D1 有证据；UAC/安全桌面已知限制书面登记。  
- 产品书面收口删旧范围与回滚方案。

## 7. UI 基线（产品 t119u/t120u 增补 · 2026-11-06）

- **直接采用** 最新入口 A 设计：**A-480-delta-v1.1**（仓内 `docs/ux-entry-a-20261106/`，此前落点约 `727d7ad`）。
- **不重选 A**，不另造一套 Tauri 专用 UI 信息架构。
- 硬约束：全态默认客户区 **840×480 DIP**；一屏双区；Waiting 显式「停止接受」；会话 **顶状态 + 页级单滚 + 滚外固定结束**；首启限幅 / 用户手调尺寸；**切态不自动加高**。
- 线框占位槽 **必须映射真实能力**，禁止占位原样上线；映射缺口只做必要差量设计评审，不重开完整选型。
- 最终仍以真实 Windows / DPI / 小工作区 UI 验收为准；设计稿 ≠ PASS。
- 首批 D0–D3 的壳与生命周期交付以本 UI 基线为准；旧 .NET 保留、官网隔离不变。
