# 宽松少问一次，日志停在末尾

设成「宽松」后，普通改动直接执行并记下来。删除、关机这类高风险仍要弹确认，拒绝就不执行。

查看日志时，结果框滚到最后一行。文件比保留的行数长时，末尾写「只显示了末尾 N 行。」短日志不写这句。路径旁的「查看」保持横排，不再被挤成两行字。

## 验收结果

本机中继 `127.0.0.1:17991`。被协助端显示「当前是「宽松」」。`echo queqiao-relaxed-ok` 没有「对方想在这台电脑执行操作」，结果是这句和 `exit=0`，记下「已执行」。`del` 仍弹出确认，按钮「允许（60）」；点「拒绝」后是「已拒绝，未做任何改动」，文件没有生成。

日志结果框露出 `queqiao-log-tail` 和「只显示了末尾 80 行。」「查看」宽 62、高 38。
