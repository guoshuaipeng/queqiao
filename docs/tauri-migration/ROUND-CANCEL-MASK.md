# 取消连接，以及弹窗不透出原文

协助端在等待对方允许时点「取消」：先作废这一代并关掉自己的套接字，回到首页，不进入会话。被协助端发现对方已经断开，关掉「有人想协助这台电脑」，仍停在等待，并重新听下一次连接。不把这次断开画成开启失败，也不进入「正在接受协助」。

配对弹窗用实底遮罩。弹窗开着时，原文框不填入连接凭证，避免从半透明遮罩里透出来。

## 验收结果

本机中继 `127.0.0.1:17991`。被协助端先到等待（密码是圆点）。协助端连上后出现「有人想协助这台电脑」。这时界面树上没有凭证原文。点「取消」后弹窗消失，仍有「等待对方连接」和「复制连接凭证」，没有「正在接受协助 · 已连接」。协助端没有「取消」，有「连接」，没有「正在协助对方 · 已连接」。

图：`acceptance/desktop-before-cancel.png`、`desktop-cancel-dialog.png`、`desktop-after-cancel-helper.png`。被协助端取消之后原文框又出现，整窗没有保存。

`npm run check` 9 项通过。`cargo test` 17 项通过。发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
