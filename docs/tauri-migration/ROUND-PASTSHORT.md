# 短的旧结果滚轮不带动整页，行尾旁的短行留着

之前的结果只有几行、自己滚不动时，在框里滚轮，整页不要跟着动。

这种短的旧结果里有一行很长时，滑到行尾后 `exit=0` 仍留在左边。

## 做法

滚轮落在之前的结果上时，框自己没有竖向可滚的距离，也不把滚动交给整页。短行按横向位置留在左边。这段拦截前面已经写上，这一轮用点击把「旧结果只有几行」测实。

## 验收结果

本机中继 `127.0.0.1:17991`。协助页先被临时撑高，上面还能滚 80，下面还能滚 257。之前的结果有 2 行，竖向可滚距离是 0，横向可滑 730。

在之前的结果里向上、向下各滚一下：整页仍是 80，旧结果仍是 0。

再滑到行尾：横向 718，整页仍是 80。`exit=0` 在 37–77，`QUEEND` 在 724–764，都在框里。

图：`acceptance/desktop-pastshort-before.png`、`desktop-pastshort-after.png`、`desktop-pastshort-tail.png`。前两张为了让整页能够滚动，临时加了底部空白。图里没有完整连接凭证。

这一轮的横滑是直接把滚动位置拨到头，没有用横向滚轮。横向滚轮会不会带动整页，没有另测。

`npm run check` 48 项通过。`cargo test` 23 项通过。滚动代码沿用前面几轮，发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。

## 下一轮只做这两件

1. 需求：在之前的结果里用横向滚轮滑到行尾，整页不要跟着上下或左右动。
2. 小修：这样滑到之后，`exit=0` 仍留在左边，`QUEEND` 仍在框里。
