# 关掉再打开两条都在，早的还能往上翻

拒绝和允许写在本机。关掉再打开，两条都还在。

记录很多时，打开先看到最近的几条。往上翻，能看到更早的「已拒绝这次协助」。列表在卡片里面滚，不把「开启接受协助」挤出去。

## 验收结果

本机中继 `127.0.0.1:17991`。先拒绝，再允许，再查看程序多次。结束并关掉进程。同一目录再打开，两条都在。打开记录时先看到最近的「查看正在运行的程序」，最早那条不在眼前。往上翻之后，「已拒绝这次协助」和「已允许这次协助」都出现。开启按钮仍完整。
