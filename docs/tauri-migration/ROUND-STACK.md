# 页面叠加修复（设计说明）

空闲窗口只做一件事：双栏首页。会话页、设置、信任条、弹窗互相挡住，不能同时出现。弹窗必须先有标题和正文，焦点在拒绝或取消。

原因是样式里的 `display: flex` 压过了 `hidden`。修法是 `[hidden] { display: none !important; }`。不增加页面，也不加深色主题。

窄于 760 像素时两栏改为上下，整页在 `#home` 里滚动。系统缩放以窗口 DPI 为准；本机是 96（100%），不改用户的缩放设置。

## 验收限制

- 桌面图是 WebView2 窗口画面：`acceptance/desktop-idle.png`、`desktop-settings.png`、`desktop-narrow.png`。
- 带 `-browser` 的图是浏览器夹具，不是桌面。
- 本机两个进程对 `127.0.0.1:17991` 弹出过真实配对窗；不是两台电脑，也不是生产中继。含凭证的图已删除。
- 自动化点复制得到「没能复制，请再点一次。」，并出现原文框。
