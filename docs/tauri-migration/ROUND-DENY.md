# 拒绝一项改动，以及对方不在等待

协助端提议改动后，被协助端点「拒绝」就不执行。双方都看到「已拒绝，未做任何改动」。

中继回答对方不在、或凭证已经对不上时，协助端说「对方现在没有在等待协助。请让对方重新开启，再发一次连接凭证。」连不上中继本身仍说检查网络。

## 验收结果

本机中继 `127.0.0.1:17991`。双方已连接。提议改动后出现「对方想在这台电脑执行操作」。点「拒绝」后，被协助端记录和协助端结果都是「已拒绝，未做任何改动」。标记文件没有生成。

结束协助后用原凭证再连，协助端出现上面那句不在等待的话，没有「没能连上，请检查网络后重试。」

图：`acceptance/desktop-before-deny.png`、`desktop-deny-dialog.png`、`desktop-after-deny.png`、`desktop-after-deny-helper.png`、`desktop-not-waiting.png`。

`npm run check` 11 项通过。`cargo test` 18 项通过。发布构建后做了上述点击。不是两台电脑，也不是生产中继。剪贴板错误 5 仍在，本轮没有把它当成已修好。
