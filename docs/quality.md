# 鹊桥 · 质感方案

> 对照 `docs/screenshots/r003-home.png`、`r003-agent.png`、`r003-helper.png`、`r003-pair-confirm.png`，以及场景指出的三条路径断点（2026-11-05）。
> 优先级由产品拍板。不改正在进行的 R005，不加回 R003/R004 功能项。
> R005 已覆盖：已连上网络则收起「请点允许」横幅；横幅里「设置」不要折行。下面从下一项开始。
> 体验主笔；场景三条断点已并入；产品 2026-11-05 收口覆盖写入。

## 结论（改动顺序）

1. 「刷新会话码」不要和「复制码+密码」抢点击。
2. 账号 / 密码要有标签；免密连接先让人看懂该选哪台。
3. 连上之后的操作不要像控制台。
4. 首页两张卡片更像能点的按钮。

配对确认窗本身没有把步骤卡住，本方案不重做。R004 的写操作确认、复制安装说明也不纳入本方案；其中「复制安装说明」和「连接」两个实心按钮并排，作为第 3 项里协助端的一小条一并改掉。

目标：亲友发出码、协助方连上、同事免密连自己的机器时，都不会因为层级或按钮长得像而被带偏。每屏同时只有一个实心主按钮。

## 1. 刷新会话码不要抢点击（先做）

断点：亲友已经把码发了出去，右侧「刷新会话码」和主按钮「复制码+密码」并排，容易误点；一点刷新，旧码失效，对方就连不上。

改法：

- 「复制码+密码」是该屏唯一实心主按钮（蓝色，与顶栏一致），比「更多」更大、更重。
- 「刷新会话码」收入「更多」，或留在「运行状态」里但改为轻按钮，点击后先确认：「刷新后旧码会失效，已经发出去的码对方将连不上。」按钮：「刷新会话码 / 取消」。
- 「断开全部 / 断开选中」保持轻按钮，不和主按钮同一视觉权重。

验收：被协助端截图上，主按钮旁没有同等大小、同等权重的「刷新会话码」；误点刷新会先看到旧码失效的说明，不会立刻作废已发出的码。

## 2. 账号要有标签，免密连接先看懂选哪台

断点：同事运维登录时，两个空白框没有「账号 / 密码」标签；「免密连接选中」看不出要先选哪台。

改法：

- 两个输入框必须有可见标签：「账号」「密码」（placeholder 不能代替标签）。
- 设备列表里，当前选中的那台有明确选中态（高亮或对勾）。
- 未选中任何设备时，「免密连接选中」禁用；旁边或按钮下方写：「请先点选一台自己的电脑」。
- 已选中时，按钮文案改为「连接这台电脑」，或保留原按钮但能看出连的是哪一台（例如「连接：客厅电脑」）。

验收：空框上方或左侧能读到「账号」「密码」；未选设备时点不了免密连接，并有「请先点选」的说明；选中后能看出将要连接哪一台。

## 3. 连上之后不要像控制台

断点：亲友协助方和客户支持连上之后，看到「列进程 / 读日志尾 / 执行命令」，看不懂下一步该帮对方看什么。未连接时这排灰按钮也像半成品。

改法：

- 未连接时不展示常用操作那一行（包括灰色禁用按钮）。
- 连接成功后再展开，并用白话代替控制台词：
  - 「列进程」→「查看正在运行的程序」
  - 「列目录」→「查看文件夹」
  - 「读日志尾」→「查看日志」
  - 「读文件」→「查看文件」
  - 「执行命令」→「提议一项改动」
- 去掉「1. 2. 3.」编号；默认只呈现「连接对方」卡片（粘贴框 + 从剪贴板 + 连接）。账号区按第 2 项处理后，权重低于粘贴区。
- 「连接」保持该屏唯一绿色实心主按钮。「复制安装说明」改为轻按钮或文字按钮，不要和「连接」并排成两个实心主按钮。

验收：未连接截图里看不到「列进程」等灰按钮、看不到「1. 配对」这种编号；连上后五个操作都是白话；协助端同时只有一个实心主按钮（连接）。

## 4. 首页卡片更像能点的按钮

断点：首页「接受协助 / 去协助别人」意思清楚，但两块看起来不像能点的按钮。

改法：

- 整张卡片可点，有按钮态（悬停加深、按下反馈、右侧或底部有「进入」一类提示）。
- 「接受协助 / 去协助别人」字重明显高于说明句；加大卡片内边距。
- 接受协助侧视觉偏蓝，去协助别人偏绿，与后续顶栏一致。
- 不增加第三张卡片，页脚不出现 IP、端口、命令行。

验收：首页仍是两张卡片 + 「选上面一项即可」和「高级」；卡片看起来像入口而不是只读说明；页脚无技术信息。

## 仍有效的统一规则

- 层级：顶栏（名字 + 当前该做什么）→ 主区域（最少内容）→ 次要（更多、高级、断开）。未发生的事不占主层级。
- 留白：会话码、验证密码、粘贴框周围的空白大于次要按钮。
- 被协助端「关闭窗口后继续在托盘运行」如果提示框和底栏各写一次，只留一处。
- 全文默认界面不出现 Assist、MCP、ownerLink、TLS（高级里除外）。
- 不重做配对确认窗（原文和「30 秒后自动拒绝」已到位）。
- 不把 R005 的横幅收起、折行提前进本方案的开发清单（已在 R005）。
- 不改中继、协议，不做完整远程桌面。
