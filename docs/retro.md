# 鹊桥 — 迭代复盘

> 每轮结束后追加一节。通用规则晋升到 `docs/dev-rules.md`（≤15 条）。

## R000 — 启动持续迭代（2026-11-05）

- **触发**：用户要求产品 bot 自主迭代，保证易用性，可与架构师沟通并指定开发计划。
- **动作**：建立 `round-001.md` 选题机制；P2 按易用性重排；`ownerLink` 从 todo 改为待验收。
- **预防规则**：每轮必须 1 高频 + 1 小打磨；决策只进 `docs/`，再 @ 实现 bot。

## R001 — 一键复制码+密码 + 品牌「鹊桥」（2026-11-05）

- **交付**：复制码+密码主按钮；鹊桥品牌文案/安装显示名；截图三张；测试 103 绿。
- **踩坑**：统一 App 已创建 ModeSelect 后再 SetCompatibleTextRenderingDefault 会炸，--accept 进被控失败；需吞掉 InvalidOperation / 由宿主先初始化。
- **踩坑**：桌面 CopyFromScreen 易被其它窗口遮挡；验收截图改用 WinForms DrawToBitmap（	ools/UiShot）。
- **规则候选**：有 UI 的轮次优先 DrawToBitmap/专用 shot 工具，不依赖当前桌面前景。

## R000b — 场景讨论入库 + 跨平台（2026-11-05）

- **收入**：亲友连不上引导（S002，R003 候选，与失败文案合成）；客户审计回看保持 P2；同事运维 ownerLink 专项作为 R002 高频。P0 不后挪。
- **新决策**：正式做 macOS / Linux；小体积一等约束；不阻塞 Windows P0；先被控端+MCP，后对等 GUI。
- **预防**：跨平台不推倒当前 WinForms 演示；net48 对比版不上 Mac/Linux。

## R000c — 官网与接单（2026-11-05）

- 用户要求服务器上静态介绍站 + 接单/管理用户，且必须轻便（机器性能低）。
- 决策：静态页 + 独立小进程 + SQLite；订单和客户名单，不升级成用户中心；与中继账号分开；需额外放行 80。
- 预防：官网不得与中继共用 17891，也不得引入重型 Web 栈。

## R002 — ownerLink 验收 + 品牌扫尾（2026-11-05）

- **交付**：ownerLink 验收矩阵与自动化测试；协助端/被控端「无需再确认配对 / 写操作仍确认」提示；审计与客户端列表展示账号免密；品牌扫尾；截图三张。
- **踩坑**：xunit 并行 + headless 控制台确认会抢 `Console.ReadLine`，ownerLink 写确认类测试需 `DisableParallelization` 集合。
- **踩坑**：仅客户端声明 `OwnerLink=true` 不够，必须中继/测试武装的 owner 通道；伪造标志不得跳过配对窗（已单测）。
- **规则候选**：权限相关验收优先可无 UI 的 headless 矩阵 + 审计断言；截图仍用 DrawToBitmap。

## R002b — 首页亲友向文案三项（2026-11-05）

- **交付**：首页页脚只留「选上面一项即可。」；IP/端口/`--accept`/`--control` 进「高级」；去掉「（被控）」并补验证密码说明；协助入口改为「粘贴对方发来的会话码和验证密码」；验证密码与会话码同色。
- **踩坑**：无（纯文案/颜色）。
- **规则候选**：亲友首页默认零技术细节；调试信息一律折叠进「高级」。

## R003 — 连不上引导 + 首屏减负 + 访客配对窗（2026-11-05 Asia/Shanghai）

- **交付**：时刻 A 顶部横幅（允许连网 / 点了取消→打开防火墙设置）；时刻 B 四类白话（FriendConnectGuide）；被协助端首屏只强调会话码+验证密码+复制码+密码，IP/TLS/审计进「高级」，分享次要按钮进「更多」；协助端空态不报「无法连接」/remoteassist:pair；两行粘贴（输入框+剪贴板）；默认公网中继、配对区仅粘贴/剪贴板/连接；访客配对窗白话「有人想协助这台电脑」；截图 docs/screenshots/r003-*.png；测试 126 绿。

## R004 — 写操作确认白话 + 复制安装说明（2026-11-05 Asia/Shanghai）

- **交付**：确认窗标题「对方想在这台电脑执行操作」；人话主文（如「运行一条命令」「删除一个文件或文件夹」）+ 次要命令/路径细节；允许/拒绝；超时自动拒绝不自动允许；拒绝后提示「已拒绝，未做任何改动」；ownerLink 写操作仍确认。协助端主按钮「复制安装说明」（三行原文不变），复制后提示「请把安装包和这段说明一起发出去」。截图 `docs/screenshots/r004-*.png`；测试 132 绿。
- **踩坑**：确认窗不能把命令原文当唯一正文；人话与细节要拆开显示。复制提示与剪贴板正文分离，勿把「一起发出去」写进剪贴板。
- **规则候选**：亲友向确认文案集中在 Protocol（`WriteConfirmCopy`）可单测；UI 只负责排版。

## R005 — MCP 安装指引 + 联网横幅收口（2026-11-05 Asia/Shanghai）

- **交付**：协助端「如何安装 MCP」三步 +「复制 MCP 配置」；被协助端默认首屏无 MCP；已连上网络时收起「请点允许」横幅；「我点了取消」显示恢复步骤；横幅「设置」用字连接防折行。截图 ``docs/screenshots/r005-*.png``；测试 134 绿。
- **踩坑**：WinForms 中文按字折行，「设置」会被拆成「改设 / 置」——不要用 U+2060 Word Joiner（WinForms 会画成可见「0」，出现「设0置」）；在标点处主动换行并加宽横幅/按钮即可。
- **规则候选**：协助向能力（MCP）只放协助端；被协助端亲友主路径保持零 MCP。

## R006 — 界面质感四项（2026-11-05 Asia/Shanghai）

- **交付**：按 `docs/quality.md` 顺序：① 被协助端主按钮权重与刷新确认；② 账号标签 + 免密选机；③ 协助端未连接隐藏操作、连上白话、安装说明轻按钮；④ 首页整卡可点。截图 `docs/screenshots/r006-*.png`；测试 135 绿。
