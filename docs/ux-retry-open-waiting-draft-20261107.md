## 1. 结论（先读）

1. **推荐**：开启失败后，用户点「重试开启」必须走与首次「开启接受协助」**同一套开启生命周期**（新 attempt）：先进入「正在开启…」，成功则留在双区入口的 **等待对方连接**（凭证就绪 / 已监听），失败则回到开启失败；**不得**卡在失败态假成功，也**不得**跳成「已连接」。
2. **Waiting ≠ Connected**：重试成功只到等待；配对且业务会话建立才进会话页（沿 A-480，本项不重开会话布局）。
3. **本项不授编码**；剪贴板成功路径仍排除在外（失败提示/手填可沿现状，不在本方案扩做）。

## 2. 用户与场景

| 项 | 内容 |
|----|------|
| 角色 | 需要帮助的亲友（左区「请人帮我」） |
| 场景 | 曾点「开启接受协助」失败（常见：中继/网络不可达）；修好网络或本机中继已起来后，仍在**同一主窗口**点「重试开启」，期望进入可发凭证的等待态 |
| 非目标 | 协助端连接流；复制凭证成功写入；账号免密；改安全底线/绕过本机确认；改中继协议 |

---

## 3. 点击路径（主路径）

1. 左区处于 **开启失败**（见 §4 文案；主按钮为「重试开启」）。
2. 用户点 **「重试开启」**（该区唯一实心主按钮）。
3. 左区立刻进入 **正在开启**：「正在开启接受协助…」；主按钮禁用，文案改为「正在开启…」。
4. 开启成功：进入 **等待对方连接**（仍留双区入口，不换外框、不进会话页）：
   - 状态句：`等待对方连接`
   - 说明：`把连接凭证发给来帮你的人。`
   - 主按钮：`复制连接凭证`（本项**不**验收复制成功；可点、可走既有失败提示）
   - 次按钮：`停止接受`（**必有**）
5. 开启再次失败：回到 **开启失败**（§4），可再次重试；不露出半截/失效凭证。

首次从 Idle 点「开启接受协助」的成功/失败路径**不在本项新设计**，仅要求「重试开启」与其 **同生命周期、同成功落点、同失败落点**。

## 4. 逐字文案（用户可见）

| 状态 | 文案 |
|------|------|
| 开启失败 · 错误 | `没能开启接受协助，请检查网络后重试。` |
| 开启失败 · 主按钮 | `重试开启` |
| 正在开启 · 状态 | `正在开启接受协助…` |
| 正在开启 · 主按钮 | `正在开启…`（禁用） |
| 等待 · 状态 | `等待对方连接` |
| 等待 · 说明 | `把连接凭证发给来帮你的人。` |
| 等待 · 主按钮 | `复制连接凭证` |
| 等待 · 次按钮 | `停止接受` |

**禁止**在重试成功后的等待态出现：`正在接受协助 · 已连接`。

## 5. 状态与内部归属（不对用户展示内部名）

| 内部态 | 用户看到 | 是否活动 | 凭证区 |
|--------|----------|----------|--------|
| AcceptFailed | 失败句 +「重试开启」 | 否（清理完成后） | 不展示活凭证 |
| AcceptStarting（由重试进入） | 正在开启… | 是 | 不展示活凭证 |
| AcceptWaiting | 等待对方连接 + 复制 + 停止接受 | 是 | 可展示当前有效凭证（密码遮挡规则沿现状/A-480） |
| AcceptConnected | （本项不设计） | 是 | 会话页 |

规则：

- 点「重试开启」= **新 attempt 世代**；取消/失败/迟到回包不得覆盖更新世代 UI。
- 进入 Starting 前须确认失败态残留已清理；清理失败则阻断重试并人话提示，**不**静默重试。
- 右区互斥沿 A-480：左 Starting/Waiting 时，右区执行性「连接」须先确认切换；本项不改切换文案。

## 6. 失败与退出分支

| 分支 | 行为 |
|------|------|
| 重试后仍网络/中继失败 | 回开启失败；可再点「重试开启」；不假称已等待 |
| Starting 取消 | **本项默认不新增「取消开启」按钮**（与首次开启一致）；若现状已有取消则沿用并清理世代 |
| 等待中点「停止接受」 | 停止中 → 成功回 Idle；失败则停止失败 +「重试停止」（沿 A-480） |
| 等待中对方连上并完成本机允许 | 进会话（既有流程）；本项只要求到达等待即可验收 |
| 迟到的旧失败/旧成功回调 | 忽略对 UI 的覆盖；关闭迟到半开资源 |
| 剪贴板 | **不在范围**；等待态复制按钮可存在，成功写入不作为本项验收 |

**前置**：同一主窗口；先制造开启失败 → 出现失败句与「重试开启」→ 再使中继可用。

| # | 条件 | 期望 |
|---|------|------|
| A1 | 点「重试开启」 | 进入「正在开启接受协助…」；主按钮禁用；仍双区入口，外框尺寸不变 |
| A2 | 开启成功 | 左区为「等待对方连接」；有「复制连接凭证」「停止接受」；**无**「正在接受协助 · 已连接」 |
| A3 | 开启再失败 | 回到失败句 +「重试开启」；无活凭证 |
| A4 | 窄窗 | A1–A3 同逻辑；不因重试改外框策略 |
| A5 | 证据 | 全屏/窄窗各至少一张：失败态、重试后等待态；记录 commit/分支；**不**宣称已生产验收 |

**非本项验收**：复制成功提示、会话页、安装器、官网、R050、剪贴板错误 5 修复。
