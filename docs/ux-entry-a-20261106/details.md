## 修订要点（相对上一稿自检未通过处）

1. **默认客户区由 840×420 收至 `840×280`**：上一稿内容块仅 ~176 DIP，底空 ~236，自检判「空灰复发」。按内容贴合重算，底空目标 &lt; 80 DIP。  
2. **预览禁止「左活监听 + 右连接中」同屏并行**：改为「默认初始 / 左凭证就绪（右空闲）/ 窄堆叠」三态；互斥切换后示意单独标注「左已停用 + 右连接中」。

## 2. 布局预算（最终）

### 2.1 默认 / 断点 / 最小

| 项 | 值（客户区 DIP） | 说明 |
|----|------------------|------|
| **默认客户区** | **`840×280`** | 贴合双区紧凑块；禁止迁就旧业务页 600/700/820 |
| **并排→堆叠断点** | 宽 **&lt; 760** | 改为上下排；**高度不随切页自动变** |
| **最小客户区** | **`640×260`** | 仅为常规拖拽下限；首次启动工作区不足时可降至此值以下，工作区优先，配合单滚 |
| **会话态** | **外框保持用户当前尺寸**（默认同 840×280 起） | 内部单滚；**禁止**子页为塞控件自动加高 |

### 2.2 默认 840×280 · 并排逐行预算

水平：左右边距 12+12=24；中缝 8；区宽各 **(840−24−8)/2 = 404**。

单区垂直（顶对齐，**按内容高度，禁止巨卡拉满**）：

| 行 | DIP（约） |
|----|-----------|
| 区标题 | 22 |
| 说明 1–2 行 | 32–36 |
| 主控件（按钮，或码行+按钮） | 48–64 |
| 弱帮助一行 | 18–20 |
| 区内边距合计 | 20–24 |
| **单区块高合计** | **≈ 140–166** |

双区取较高块 ≈ **166**；顶边距 10 + 底边距 16 → 内容占用 ≈ **192**。  
默认高 **280** → 底空约 **≈ 70–88**（目标 &lt; 80；若实测 &gt; 120 判空灰复发，优先再减窗高，**禁止**撑卡片/加假功能）。

### 2.3 窄堆叠（例：用户拖到宽 720，高仍 280）

| 行 | DIP |
|----|-----|
| 上区块 | ≈ 150–166 |
| 区间距 | 10 |
| 下区块 | ≈ 150–166 |
| 边距 | 16 |
| **内容合计** | **≈ 326–358** |

客户区高仍为用户当前值（默认路径下常为 280）→ **触发 §2.5 单滚**；用户可手动加高。窄屏示意可用 720×280 + 滚动提示，不另设「自动加高」。

### 2.4 200% DPI · 小工作区

逻辑 840×280 → 物理约 1680×560 px。

1. 仅首次显示按可用工作区限幅，计入标题栏/边框；工作区不足时允许低于常规最小客户区，禁止以最小尺寸把外框顶出屏。此后仅用户手动拖拽改变尺寸，切态不得重复限幅改窗。  
2. 内容规则仍 §2.5。  
3. 不得为「不空」而加高超出工作区。

### 2.5 单滚动容器（硬规则）

- **唯一**页级纵滚宿主：壳 `host`（或会话页根）`AutoScroll=true`。  
- 双区入口 / 会话页内部面板：**不再**套一层页面滚动。  
- **允许**：多行输入框自身文字滚动（控件内滚动 ≠ 第二层页面滚）。  
- 会话态主操作（结束等）放首屏优先区或底栏固定带，避免只靠滚到底。  
- **禁止**双区各自滚动 + 外壳再滚；**禁止**巨卡/新功能填白。

## 3. 左区状态与文案

| 状态 | UI 形态 | 主按钮 | 是否算「活动」 |
|------|---------|--------|----------------|
| 未启用 | 无码、无监听 | `开启接受协助` | 否 |
| 正在开启 | 等待中 | `正在开启…`（禁用） | **是** |
| 开启失败 | 人话错误 | `重试开启` | 否 |
| **凭证就绪 / 中继 Waiting** | **仍留在双区入口**；码可显、密码遮挡；已监听可被连 | `复制连接凭证`；可提供 `停止接受`（若现状已有则沿用） | **是** |
| **被控 Connected（业务会话已建立）** | **会话布局**（非入口双区条） | 见会话/结束 | **是** |

| 键 | 原文 |
|----|------|
| 区标题 | `请人帮我` |
| 未启用说明 | `先开启后，才能复制连接凭证发给来帮你的人。` |
| 主按钮开启 | `开启接受协助` |
| 开启失败 | `没能开启接受协助。` / `请检查网络后重试。` |
| 就绪说明 | `把连接凭证发给来帮你的人。` |
| 复制按钮 | `复制连接凭证` |
| 帮助 | `默认通过中继连接` |

**Agent 就绪条 vs 真会话：**

- **凭证就绪 / Waiting**：继续画在一屏双区内（左区就绪条）；**不是**完整业务会话页。  
- **Connected（已配对且业务会话建立）**：切到会话布局；**外框 ClientSize 不变**；需要时内部单滚。

**复制反馈：** **不作为本入口已放行实现范围**。可沿用现状或另项待收口（如三秒「已复制」）；**勿写入本细则必做验收。**

复制载荷 = 现行完整 pair（含 fp）。示意/日志禁用真实密钥。

**初始：** 不开监听、不出现活凭证。

## 5. 错误分层（本地 ≠ 网络）

### 5.1 本地（点「连接」后、发起建连前）

| 分因 | 文案 |
|------|------|
| 格式无法识别 | `连接凭证格式不对，暂时连不上。` + `请让对方重新点「复制连接凭证」，把复制到的内容原样粘贴。` |
| 缺码/密码或**缺安全校验信息（含缺 fp 等）** | `连接凭证不完整，暂时无法连接。` + `请让对方重新复制完整连接凭证后再发。` |

- **禁止** short-code-only 放行。  
- **禁止**点连接前单独做「网络未通」预判态（不提前联网探测挡用户）。  
- 空输入保持 `连接` 禁用，不进入本层。

### 5.2 建连之后（已发起连接尝试）

| 分因 | 文案方向 |
|------|----------|
| 网络/中继不可达、超时 | `没能连上，请检查网络后重试。` |
| 对端拒绝/无法配对等 | 沿用既有协助端失败人话；**不**与「格式不对」混用 |
| 用户取消 | 回可编辑；见 §7 |

仅在实际发起建连后才出现网络类错误。

## 6. 单活动角色互斥（覆盖未连上）

「活动」**不只**「已连接」，包括：

| 活动侧 | 含义 |
|--------|------|
| 左 · 正在开启 | 开启流程未结束 |
| 左 · 凭证就绪 / **中继 Waiting** | **已监听**（可被连）；入口双区条 |
| 左 · 被控 **Connected** | 已有人连上；会话布局 |
| 右 · **连接中** | 正在建连（含 client 仍为 null） |
| 右 · **Connected** | 协助中；会话布局 |

**仅查看**另一区文案/只读信息：**不暗断**、不改状态。

### 6.1 冲突操作 → 先确认

| 当前 | 用户动作 | 处理 |
|------|----------|------|
| 左就绪/Waiting/会话中 | 右点「连接」 | 先确认 §6.2 |
| 左正在开启 | 右点「连接」 | 先确认；确认则**先停开启**成功后再连 |
| 右连接中/已连接 | 左点「开启」 | 先确认 |
| 任一侧活动 | 对侧**执行性**动作 | 同须确认 |

确认「继续」且停监听/取消连接/**断开失败** → **不得进入目标动作**，留原状态并提示失败。

### 6.2 确认框逐字

**标题：** `切换会打断当前操作`

**正文（非会话）：** `当前已经在「请人帮我」或「我帮别人」一侧进行中。继续将先停止这一侧，再执行另一侧。取消则保持现在的状态，不会断开或停止。`

**正文（已会话）：** `现在有正在进行的协助。继续将先结束当前这次，再切换。取消则继续当前协助，不会断开。`

**按钮（按当前状态二选一显示）：** 非会话用 `停止并切换` / `取消`；已会话用 `结束并切换` / `取消`。正文中的“继续”指点选对应切换按钮。

**键盘 / 默认：**

- **默认焦点 / 默认按钮 =「取消」**  
- **Esc = 取消**  
- **Enter 不得**绑定为「继续 / 结束并切换」（避免误结束）

### 6.3 过期「开启」回包

用户已取消开启、或确认后已切到右侧流程后：

- **迟到的开启成功**不得恢复监听、不得露出新凭证；  
- 丢弃过期 `attemptId`；本端按现有通道停止误开的监听；  
- **不假称**服务端可撤销；不新协议。

## 7. Helper 取消、世代与 Disable

| 规则 | 说明 |
|------|------|
| 取消起点 | 从**发起连接尝试**起即可取消（不必等 client 非 null） |
| client 可能 null | 连接中 UI 仍显示「正在连接…」+`取消`；取消逻辑不依赖 client 已创建 |
| `attemptId` / 世代 | 每次发起递增；取消或新尝试使旧世代过期 |
| 迟到成功 | 过期世代：**不**进会话、**不**改 UI 为已连接、**不**覆盖较新尝试；关闭本次迟到资源，并按现有安全通道清理半开连接；不得仅忽略回调而保留活连接 |
| **按钮 Disable ≠ 取消** | 对侧禁用、控件禁用、窗口失活 **不等于**取消当前连接尝试；唯显式「取消」或确认切换后的停止流程才取消 |
| 新尝试 | 清理旧尝试后再开新世代；迟到旧成功不得盖住新尝试 |

## 13. 验收矩阵（摘要）

- 默认 **840×280** 并排，无巨卡空灰（底空目标 &lt; 80；&gt; 120 判回）。  
- 窄 &lt; 760 堆叠；同高不足则单滚；200% 先 Fit 工作区。  
- 单一页级纵滚；输入框文字滚允许；禁止嵌套两层页面滚。  
- 活动含：左开启中 / 就绪·Waiting / Connected；右连接中 / Connected。  
- 查看对侧不暗断；冲突先确认；默认取消；Esc 取消；Enter 不结束；停/断失败不进目标。

- 本地缺 fp/格式先于网络；空禁连；完整 pair+fp 显式点击才联网；初始左不开监听。  
- 复制三秒反馈非本项必做；结束只沿现行有效性。  
- 固定外框覆盖 ShowHome/Accept/Control 与 Helper 自动改 ClientSize。  
- 标题栏/任务栏图标一致性凭证据；不扩安装器。
