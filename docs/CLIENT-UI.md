## 0. 设计原则（五条）

1. **一个窗口**：所有页面在同一窗口内切换，不弹第二个主窗口。只有安全确认用弹窗。
2. **一屏两件事**：打开就能看到「请人帮我」和「我帮别人」，不需要先选模式再跳页。
3. **一个按钮推进一步**：每个状态只有一个主按钮（蓝色实心），其余都是次要按钮或文字链接。
4. **只说人话**：界面不出现 中继、TLS、指纹、fp、PAIR_OK、Assist、Admin、MCP（MCP 只在设置里出现）。
5. **安全不打折**：配对确认、改动确认、完全信任二次确认一律保留；简化只简化步骤，不简化授权。

## 1. 窗口与整体布局

| 项 | 规则 |
|----|------|
| 默认大小 | 840 × 480（逻辑像素，不含标题栏）；用户可拖动，切页不改窗口大小 |
| 最小参考 | 640 × 360；宽度 < 760 时左右两区改为上下排列，整页一个纵向滚动 |
| 顶栏（固定） | 左：鹊桥图标 + 「鹊桥」；右：「个人中心」+ 齿轮图标「设置」 |
| 底栏 | 只在**会话中**出现，固定在底部，放「结束本次协助」 |
| 字号 | 标题 20、区块标题 18、正文 14–16；按钮高 36–40 |
| 颜色 | 主按钮蓝；已连接绿；警告（完全信任、出错）橙/红。状态必须有文字，不能只靠颜色 |

关闭窗口：无活动时直接退出；有活动（等待中 / 会话中）时弹确认（见 §6.5）。不偷偷缩到托盘后台。

## 2. 首页（一屏两区）

```
┌──────────────────────────────────────────────────────────┐
│ 🌉 鹊桥                                          ⚙ 设置 │
│ 亲友之间，发凭证或粘贴连接。                             │
│ ┌───────────────────────┐  ┌───────────────────────────┐ │
│ │ 👤+ 请人帮我           │  │ ▶▣ 我帮别人               │ │
│ │ 让信任的人帮你查电脑。 │  │ 粘贴对方发来的连接凭证。   │ │
│ │                        │  │ ┌───────────────────────┐ │ │
│ │ [ 开启接受协助 ]       │  │ │ 粘贴连接凭证           │ │ │
│ │                        │  │ └───────────────────────┘ │ │
│ │                        │  │ [ 连接 ]（空输入时灰）    │ │
│ └───────────────────────┘  └───────────────────────────┘ │
│ 只把连接凭证私下发给你信任的人。                         │
└──────────────────────────────────────────────────────────┘
```

- 启动时**两区都是空闲**：不自动开启接受协助，不自动读剪贴板，不自动连接。
- 两区同等大小、同等层级；视觉对齐方案 B：独立圆角卡片（非左右拼板）、留白更大、主按钮扁平蓝、底栏浅灰安全提示。
- 区标题左侧各有一个圆角色块图标：「请人帮我」用加人（蓝底），「我帮别人」用显示器播放（靛底），与标题横排对齐。
- 右区凭证输入左侧有钥匙图标；安装说明链接居中。

## 3. 左区「请人帮我」（被协助的人）

### 3.1 状态与文案

| 状态 | 区内显示 | 主按钮 | 次要操作 |
|------|----------|--------|----------|
| 空闲 | 未开启接受协助 | **开启接受协助** | — |
| 开启中 | 正在开启接受协助… | 开启（禁用） | — |
| 开启失败 | 没能开启接受协助，请检查网络后重试。 | **重试开启** | — |
| 等待对方 | 等待对方连接<br>会话码 `123 456 789`<br>密码 `••••••••` 👁 | **复制连接凭证** | 停止接受 |
| 停止中 | 正在停止接受协助… | （全部禁用） | — |
| 停止失败 | 没能停止接受协助，请重试。 | **重试停止** | — |
| 有人请求连接 | 弹出**配对确认窗**（§6.1） | — | — |
| 已连接 | 进入「接受协助会话页」（§5.1） | — | — |

### 3.2 交互细节

- 会话码大字显示，方便口述；密码默认遮挡，点眼睛图标才显示。
- 点「复制连接凭证」：剪贴板真正写入成功后，按钮下方出现 3 秒提示「已复制，请完整发给对方。」；失败提示「没能复制，请再点一次。」
- 复制的内容对用户统一叫「连接凭证」。底层现在是完整安全载荷（含证书指纹），R050 落地后换成「会话码-密码」短串——**界面和操作不变**，只换内容。
- 「停止接受」：停止成功才回空闲，并不再显示旧凭证。
- 首次开启时区下加一行灰字：「开启后，把连接凭证发给来帮你的人，再等对方连接。」

## 4. 右区「我帮别人」（协助方）

### 4.1 状态与文案

| 状态 | 显示 | 主按钮 |
|------|------|--------|
| 空输入 | 输入框占位「粘贴连接凭证」 | 连接（禁用） |
| 已输入 | 可编辑；**不**自动连接 | **连接** |
| 格式错误 | 连接凭证格式不对，暂时连不上。请让对方重新复制后原样发来。 | 连接 |
| 凭证不完整 | 连接凭证不完整，暂时无法连接。请让对方重新复制完整连接凭证后再发。 | 连接 |
| 连接中 | 正在连接对方… | 取消 |
| 等对方点允许 | 已找到对方，等对方点「允许协助」… | 取消 |
| 对方拒绝 | 对方没有同意这次协助。 | 连接 |
| 连接失败 | 没能连上，请检查网络后重试。 | 连接 |
| 已连接 | 进入「协助会话页」（§5.2） | — |

### 4.2 交互细节

- 格式校验在本地完成，**校验不过不联网**。
- 输入框右侧有小链接「粘贴」，一键从剪贴板填入（用户主动点才读剪贴板）。
- 「取消」立即生效，之后迟到的连接结果一律丢弃并关闭，不会突然跳进会话。
- 输入框下方小字链接「对方还没装鹊桥？复制安装说明」——复制带官网下载地址的一段话。

## 5. 会话页（连上之后，替换首页内容，窗口不变）

两种会话页结构相同：**顶部状态条（固定）+ 中间内容（唯一滚动区）+ 底部结束栏（固定）**。

### 5.1 接受协助会话页（被协助的人看）

```
┌──────────────────────────────────────────────────────────┐
│ 🌉 鹊桥                                          ⚙ 设置 │
│ ● 正在接受协助 · 已连接                                  │
│ ⚠ 当前是「完全信任」：这次协助的改动不会再问你。[结束完全信任] │  ← 仅非默认档时出现
├──────────────────────────────────────────────────────────┤
│ 对方已连接。请核对对方身份，不要随便信任陌生人。         │
│                                                          │
│ 对方做过的事                                             │
│  16:32  查看正在运行的程序                               │
│  16:33  查看日志  C:\…\app.log                           │
│  16:35  ✔ 已允许：重启服务 Spooler                       │
│  16:36  ✖ 已拒绝：删除文件 C:\temp\a.txt                 │
│  （空态：对方还没有做任何操作）                          │
├──────────────────────────────────────────────────────────┤
│                                     [ 结束本次协助 ]     │
└──────────────────────────────────────────────────────────┘
```

- 「对方做过的事」：本机实时记录，只存本地；结束后在首页左区可通过「查看上次协助记录」回看。
- 信任档提示条：
  - 每次询问（默认）：不显示。
  - 宽松：浅色条「当前是「宽松」：只有高风险改动才会问你。」+「改回每次询问」。
  - 完全信任：橙色条「当前是「完全信任」：这次协助的改动不会再问你。」+「结束完全信任」。
- 对方每次要改动，弹**改动确认窗**（§6.2），按信任档决定是否弹。

### 5.2 协助会话页（协助方看）

```
┌──────────────────────────────────────────────────────────┐
│ 🌉 鹊桥                                          ⚙ 设置 │
│ ● 正在协助对方 · 已连接                                  │
├──────────────────────────────────────────────────────────┤
│ 常用操作                                                 │
│ [查看正在运行的程序] [查看文件夹] [查看日志] [查看文件]  │
│ [提议一项改动]                                           │
│                                                          │
│ 结果                                          [复制结果] │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ （空态：点上面的操作，结果会显示在这里）             │ │
│ └──────────────────────────────────────────────────────┘ │
│ ▸ 之前的结果（按时间倒序，接在下面同一滚动区）           │
├──────────────────────────────────────────────────────────┤
│                                     [ 结束本次协助 ]     │
└──────────────────────────────────────────────────────────┘
```

- 「查看文件夹 / 日志 / 文件」点击后，按钮下方展开一行路径输入框 +「查看」，不弹窗。
- 「提议一项改动」：展开输入（要做什么 + 命令），点「发给对方确认」。状态依次显示：
  等对方确认… → 对方已允许，正在执行… → 已完成 / 已拒绝，未做任何改动 / 对方没有回应，已自动取消。
- 一次只跑一个操作；执行中其余操作按钮禁用，并显示「正在执行…」。
- 对方结束：顶部状态变灰「对方已结束这次协助。」，常用操作收起，底栏按钮变为「返回首页」。

## 6. 弹窗（只有这五种）

所有弹窗：默认焦点在**取消/拒绝**；Esc = 取消；超时 = 拒绝（绝不超时自动允许）。

### 6.1 配对确认（被协助端）

- 标题：有人想协助这台电脑
- 正文：对方可以查看进程、日志和文件，不能直接改你的电脑。真正要改动时，还会再问你。
- 按钮：**允许协助** / 拒绝（60 秒无操作自动拒绝，按钮上显示倒计时）

### 6.2 改动确认（被协助端）

- 标题：对方想在这台电脑执行操作
- 正文：白话说明（如「重启服务 Spooler」）；命令原文折叠在「查看详细」里。
- 按钮：**允许** / 拒绝。拒绝后在记录里显示「已拒绝，未做任何改动」。

### 6.3 打开完全信任（被协助端，设置里触发）

- 标题：这次协助不再询问了吗？
- 正文：打开后，只对现在这位协助者、这一次有效。对方做的改动都不会再弹窗问你，但仍会记在这台电脑的记录里。你可以随时改回。这次结束后，或换一个人再连，不会继续完全信任，会回到你平时的选择。
- 按钮：确定，这次不再询问 / **取消**

### 6.4 结束 / 切换角色

| 场景 | 正文 | 按钮 |
|------|------|------|
| 会话中点「结束本次协助」 | 结束后对方会断开。这个连接凭证不能再用，下次需要重新开启。 | 结束协助 / **取消** |
| 等待中去点右区「连接」 | 切换会停止当前的接受协助。 | 停止并切换 / **取消** |
| 会话中想切换角色 | 切换会结束当前这次协助。 | 结束并切换 / **取消** |

- 同一时间只能有一个角色在活动；切换必须先停干净旧的，再开始新的。停失败就留在原状态并提示重试。
- 结束成功回首页空闲；再次接受协助必须重新点「开启接受协助」。

### 6.5 退出程序（有活动时关窗）

- 正文：退出会断开当前连接，并停止接受协助。
- 按钮：退出 / **取消**

## 7. 设置页（同窗打开，左上「← 返回」）

视觉：**方案 B**（浅底滚动区 + 分组卡片；见 `client-ui-mockup.html` ⑧）。口径仍如下四组：

1. **对方要改这台电脑时**（单选，默认「每次询问」）
   - 每次询问 — 对方改动前都会问你（推荐）
   - 宽松 — 只有高风险改动才问你，其余会记下但不再打扰
   - 完全信任 — 仅这次不再询问，但会记下（选中时先弹 §6.3）
   - 小字：高风险包括删除文件、关机、改权限等。如果对方只能查看，不会因为这个设置就能改你的电脑。
2. **连接服务器**
   - 一般不用改。只有对方或管理员告诉你换服务器时才改这里。
   - 地址输入框 +「保存」+「恢复默认」；必须点保存才生效，保存成功提示「已保存。新的连接会使用新地址。」
   - 会话中保存时提示：当前这次协助仍走原来的服务器，结束后重新连接才会用新地址。
3. **给 AI 助手用（MCP）**
   - 一句说明 +「复制 MCP 配置」+「复制使用说明」。
4. **关于**：版本号、官网链接、「查看协助记录」（打开本地记录目录）。

## 7.1 个人中心（同窗打开，左上返回；方案 B）

> 账号 / 设备列表能力见 `docs/round-052.md` 与 `PRODUCT.md`「恢复账号设备免密」。亲友临时凭证路径仍保留。效果图：`client-ui-mockup.html` ⑨。

入口：顶栏「个人中心」（与「设置」并列或从设置进入均可；实现时二选一，效果图先按独立同窗页）。

已登录时从上到下：

1. **账号卡**：头像字、用户名、状态「已登录 · 可管理自己的电脑」；「管理账号」「退出登录」。
2. **允许我的账号连接这台电脑**（开关，默认关；效果图演示为开）
   - 打开后本机才 `device_online`，其他已登录设备才能在列表里看到并连接。
   - 关掉或退出客户端后列表里离线，不能连。
3. **我的设备**
   - 列表：名称、系统、在线/离线；本机标「本机 / 当前这台」。
   - 在线非本机：「连接」（免输会话码、不弹配对窗；改动默认仍弹确认）。
   - 离线：「连接」禁用。
   - 「刷新列表」。
4. **底栏提示**：在线设备可直接连接，不必再输会话码；改动默认仍会问对方确认。

未登录时：同窗展示注册/登录（用户名 3–32 位字母数字下划线；密码至少 8 位；无手机号/邮箱/找回）。效果图本版只画已登录态。

## 8. 长久码（第二阶段，默认隐藏）

> 用户已确认「临时码 / 长久码两类并列」及「长久码可另配改动不再询问」。**无人值守仍未确认，本版不做。** 第一版只做临时码，界面保持简单。

- 入口：首页左区底部文字链接「我的长久码」→ 同窗打开列表页。
- 列表每条：名称（可改）、会话码、密码（遮挡）、「复制连接凭证」、「改动时不再询问」开关（默认关，打开需二次确认）、「撤销」。
- 创建前必弹：「长久码和密码谁拿到都可以连接这台电脑。请只存在你信任的设备上。创建后不会自动允许改动。」
- 撤销：立刻失效并断开正在用它的连接。结束临时协助**不影响**长久码。
- 长久码连接时仍要现场点「允许协助」（无人值守未确认前）。
