## 2. 首批技术范围（产品门槛 · 细则架构/客户端后续写）

- **Windows 首批**：Tauri 壳 + **Rust 原生**系统能力（命令 / 截屏 / 注入 / 剪贴板等按能力清单落地）。  
- **协议兼容**：现有 **pair / fp** 与 **relay** 兼容；协助/被控安全路径不降级。  
- **交互意图**：对齐入口 A 方向的状态 / 取消 / 清理（显式启动、单会话互斥、取消使本次失效、清理失败阻断双开等）——以迁移规格为准，不假装 net48 已验。  
- **测试重点**：权限 / UAC / sidecar 生命周期。  
- **禁止**：降级短码单独建业务通道；静默失败；削弱配对/信任档/完整凭证门槛。
