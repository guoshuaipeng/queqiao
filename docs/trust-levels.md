# 信任等级（被协助端）

> 产品拍板：2026-11-05 Asia/Shanghai。场景写闭环，体验写入口与原文，产品收口合并写入。
> 不写入 R005。实现排在 R007，等 R005/R006 收口后再交给客户端。

三档都由被协助的人在本机改，对方不能远程打开。协助权限决定对方能提议什么，信任等级决定本机还问不问。访客只读仍是天花板：即便本机开了完全信任，访客也不能写。完全信任不是把对方升级成管理员，只是本机决定这一次不问了。界面不出现 Assist、Admin、ownerLink。客户支持仍靠审计回看「刚才改了什么」，不另做工单。

## 范围与失效

完全信任只对「当前会话 + 当前这位已连接的协助者」有效。会话结束、刷新会话码、断开后换人、新访客重新配对后都不沿用。

每次询问和宽松可以记成本机偏好。完全信任不能设为开机默认，也不能跨会话保存。结束后回到本机保存的「每次询问」或「宽松」，没有保存过就回「每次询问」。

## 每次询问（默认）

- 用户：亲友或客户把电脑交给别人看，希望每一步改动都看见。
- 场景：对方提议任何写操作。
- 步骤：本机弹出确认（人话说明，命令原文可放次要位置）→ 允许才执行 / 拒绝则未做任何改动。
- 验收：出厂默认就是这一档；未改设置时，删文件、执行命令、改权限都要问。

## 宽松

- 用户：同事排障或一次协助里小操作很多，不想每次都点，但仍要拦住高风险。
- 场景：本机主人在被协助端改到宽松。
- 步骤：非高风险写操作自动允许并记审计；高风险仍弹确认。高风险先按这些算：删除文件或文件夹、格式化、关机/重启、改用户或权限、改注册表；「执行命令」若明显属于这类意图也仍要问。
- 验收：一次非高风险写操作不弹窗，审计能查到；删文件或关机仍弹窗。这不是完美安全网，所以默认不得是宽松。

## 完全信任

- 用户：本机主人明确接受「当前这位协助者在本会话里不再询问」。
- 场景：打开前本机再确认一次；可随时改回。
- 步骤：本机确认（说明之后改动不再询问）→ 本会话内写操作不再弹窗、仍记审计 → 会话结束或换人后不带到下一个访客。
- 验收：只对当前这位协助者+当前会话有效；断开、刷新会话码或新访客配对后，不得仍是完全信任。访客只读的对方即使开了完全信任也不能写。对方不能远程打开此档。

## 界面名称

三档名称就用产品拍板的：**每次询问**（默认）、**宽松**、**完全信任**。

| 名称 | 一行说明（写在选项下方） |
|------|--------------------------|
| 每次询问 | 对方改动前都会问你（推荐） |
| 宽松 | 只有高风险改动才问你，其余会记下但不再打扰 |
| 完全信任 | 仅这次不再询问，但会记下 |

界面上可用一句补充：「高风险包括删除文件、关机、改权限等。」不必把清单做成主文案。

## 设置入口

- 位置：被协助端 →「高级」→ 分组标题「对方要改这台电脑时」。
- 形态：三选一（单选）。默认选中「每次询问」。完全信任选项旁加小字「仅这次」，不能设成开机默认，也不能跨会话保存。每次询问、宽松改了就记成本机偏好。
- 只能在这台被协助的电脑上改。协助端、MCP、远程命令都没有入口。
- 打开「完全信任」不能直接生效，必须先过本机二次确认（原文见下）。「每次询问」「宽松」可以直接选中；从「完全信任」改回这两档也不再二次确认。
- 访客只读仍是天花板。分组下用一行小字：「如果对方只能查看，不会因为这个设置就能改你的电脑。」

验收：协助端和远程侧找不到该设置；被协助端「高级」里能看到三档且默认是「每次询问」；选「完全信任」会先弹出二次确认，取消则仍停在原来的档。

## 打开完全信任时的二次确认（原文）

标题：这次协助不再询问了吗？

正文：打开后，只对现在这位协助者、这一次有效。对方做的改动都不会再弹窗问你，但仍会记在这台电脑的记录里。你可以随时改回。这次结束后，或换一个人再连，不会继续完全信任，会回到你平时的选择。

按钮：「确定，这次不再询问」 / 「取消」

验收：未点「确定，这次不再询问」时，档位不会变成完全信任；正文包含「只对现在这位协助者、这一次有效」「不再弹窗」「会记下」「可改回」「换人不会沿用」「会回到你平时的选择」。

## 当前不是默认档时的可见提示

默认「每次询问」时，主界面不额外提示。

宽松（被协助端主界面顶部或状态区，浅提示，不要用错误红）：

> 当前是「宽松」：只有高风险改动才会问你。
> 操作：「改回每次询问」

完全信任（同样位置，警告色，比宽松更醒目）：

> 当前是「完全信任」：这次协助的改动不会再问你。
> 操作：「结束完全信任」

点「改回每次询问」（宽松）立即把本机偏好改回每次询问。点「结束完全信任」只结束这一次完全信任，回到本机已保存的每次询问或宽松，不要把平时选择改成每次询问。两枚按钮都立即生效，不用再确认。同一位协助者、同一次会话中途改档立即生效。

会话结束、刷新会话码、对方断开并换人再连后，完全信任必须失效，档位回到本机保存的「每次询问」或「宽松」（没有保存过就回「每次询问」），对应提示消失。宽松若已保存为本机偏好，换人后再连仍可以是宽松，主界面继续显示宽松提示；它不能变成完全信任。

验收：宽松时主界面能看到当前档和「改回每次询问」；完全信任时看到当前档和「结束完全信任」；每次询问时没有这条提示；结束完全信任后若平时是宽松，应回到宽松而不是被改成每次询问；换人再连后不会还停在完全信任。
