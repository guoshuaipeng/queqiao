## A · 一屏双区（推荐优先考虑）

**结构**：取消「先选角色」首页。同一固定壳内并排（或上下）两区：  
左/上 **「我的连接凭证」**（展示+「复制连接凭证」）；右/下 **「连接对方」**（粘贴框+「连接」）。远程协助建立后，**原壳**切到对应业务区（被控会话态或协助工具态），不新开主窗。

**亲友路径（例）**  
1. 打开应用 → 同屏看见「我的凭证」与「连接对方」。  
2. 若请人帮：点复制 → 发给对方。  
3. 若帮别人：粘贴对方发来的凭证 → 点连接。  
4. 连上后壳内进入业务区（状态/工具）；可结束回双区或留在会话态（实现时定，不假装多会话）。  
5. （可选）拖拽调整窗大小，布局两区随宽适配。

**利弊一句**：少一次角色选择、路径最短；同屏两意图需防误点「连接」空粘贴，文案分区要极清晰。  
**适用**：亲友互助、第一次使用、两角色常互换的同一人。  
**改动边界 / 依赖**：重做入口 IA（替换 ModeSelect 角色二选一）；壳内嵌双区+连上后换页；依赖既有复制/粘贴/连接管线。不改载荷与配对。实施需定双区在窄宽下的堆叠规则。

---

## B · 顶部两标签（低风险备选）

**结构**：无独立「选角色」首页。顶栏两标签：**「请人帮我」**（默认）、**「我帮别人」**。固定外框内切标签内容；进会话后仍在同壳（标签可改为会话态或保留可切）。

**亲友路径**  
1. 打开 → 默认在「请人帮我」：看码/复制。  
2. 发给来帮你的人。  
3. 若要帮别人：点标签「我帮别人」→ 粘贴 → 连接。  
4. 连上后同壳业务区。  
5. 可拖拽窗体；切标签不改外框。

**利弊一句**：仍显式分角色、改动面小于 A、心智接近现状；比现状少「首页再进一层」，但仍多一次点标签。  
**适用**：习惯「我是被控/控制」二分的用户；团队想小步替换 ModeSelect。  
**改动边界 / 依赖**：Shell 顶栏 Tab + 两页内容（接受/协助表单）；去掉或降级 ModeSelect。连接/复制逻辑复用。风险低、IA 变化中等。

---

## C · 任务向导（两步）

**结构**：固定壳内先问一句：**「你手上有对方发来的连接凭证吗？」** → **有** → 粘贴+连接；**无** → 出示「我的连接凭证」+复制。不先抽象选角色。

**亲友路径**  
1. 打开 → 看到是/否（或「有凭证 / 没有，我要请人帮」）。  
2a. 有 → 粘贴 → 连接 → 业务区。  
2b. 无 → 复制我的凭证 → 发给对方 → 等待（停留出示页或简态）。  
3. 若答错可「返回重选」。  
4. 外框固定；可拖拽。

**利弊一句**：任务语言贴亲友；多一步问答，老用户可能嫌烦。  
**适用**：纯小白、客服话术引导「先看你有没有码」。  
**改动边界 / 依赖**：新向导页状态机（两步）；复用复制/连接。需避免与「请人帮我/我帮别人」术语打架。不新增网络隐式行为。

---

## D · 侧栏工作区

**结构**：固定外框。左侧栏：**接受协助** / **去协助** / **当前会话**（仅当已有会话时启用；无会话时「当前会话」禁用或隐藏，**不假装列表**）。右侧为活动内容。

**亲友路径**  
1. 打开 → 侧栏选「接受协助」→ 右侧复制凭证。  
2. 或选「去协助」→ 右侧粘贴连接。  
3. 连上后侧栏「当前会话」可用 → 右侧业务区。  
4. 侧栏切换不改外框。  
5. 可拖拽。

**利弊一句**：扩展性好、像工作台；侧栏占宽，小屏挤，实现量大于 B。  
**适用**：同一人频繁切换角色、或后续要加「会话」入口时。  
**改动边界 / 依赖**：壳级侧栏+内容宿主；接受/协助/会话三态。**当前会话**无多会话时只表示「正在进行的这一次」。不实现未授权的会话管理后台。

---

## E · 会话起始页（粘贴主入口）

**结构**：首屏**主路径**是大输入：**粘贴连接凭证** + **连接**。旁或下方**次级折叠**：「请人帮我，出示我的凭证」（展开后复制）。仍**显式**区分两种意图；**禁止**仅因粘贴文本就自动建连（必须点「连接」）。

**亲友路径**  
1. 打开 → 默认聚焦「帮别人」：粘贴。  
2. 点「连接」才建连 → 业务区。  
3. 若请人帮：展开次级 → 复制我的凭证 → 发送。  
4. 可拖拽；切折叠不改外框。  
5. 清空粘贴或失败时不自动改角色。

**利弊一句**：帮别人一步直达；请人帮变成次级，亲友「我要被帮」可能不好找。  
**适用**：协助方更频繁的用户（子女帮父母时子女侧）。  
**改动边界 / 依赖**：重做起始页信息层次；复制区折叠组件。必须保留显式「连接」点击；安全确认不变。
