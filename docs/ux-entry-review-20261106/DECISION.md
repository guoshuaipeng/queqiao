## 3. 产品实现范围（限定 PV-002 入口 + 固定壳适配）

> 下列为**产品范围与行为门槛**。视觉/控件级细则由体验另文；**建议像素仅为起点**，未经全员复核 + 产品收口前**不得**写成已验收或已全员通过。

### 3.1 入口信息架构（A）

- **取消**独立角色选择首页；同壳双区：**「请人帮我」** / **「我帮别人」**（文案以体验细则为准；意图对应该左右/上下两区）。
- **左（请人帮我）**：初始 **未开启**——**不**展示活凭证、**不**启动 Agent/Host/relay；主按钮「开启接受协助」；用户**点击后**才进入生成中 / 就绪 / 失败。就绪可复制**现行完整** `pair`（含 `fp=`），**不改协议**。
- **右（我帮别人）**：本地输入；空框时「连接」**禁用**；无效 / 缺 `fp` 在建业务通道前**阻断**；**只能**明确点击连接；**不**自动读剪贴板、**不**因失焦联网。

### 3.2 单活动角色 / 单会话

- 状态机方向：`Idle` → `AcceptStarting` / `AcceptWaiting` / `AcceptConnected` **或** `ControlConnecting` / `ControlConnected`。
- **两区可见 ≠ 两角色同时启动**。默认有活动时，另一意图**不可直接发起**；显示解释 + 显式「结束当前并切换」；沿用现有本机确认；取消则保留原会话；旧生命周期完成 Leave/Dispose 后才新建；清理失败保持错误 / 阻断，**不能双开**。
- 切页 / 缩放 / 查看**不**重新注册、**不**自动结束。

### 3.3 连接中 / 失败 / 断连

- 连接中防重入、可取消；取消令**本次尝试失效**；迟到成功**不得**推进状态；失败保留可编辑输入。
- 断连给出真实状态 + 显式重试；**不**自动重连。

### 3.4 会话成功与结束

- 成功后同一壳显示对应业务页与持久状态 + 结束操作；可查看入口但**不**结束 / 新建生命周期。
- 结束确认后清理连接 / 监听，回双区 `Idle`；**严格保留**既有凭证有效性 / 刷新语义；**不**承诺「结束永久作废码」或新多码（另案未来设计）。
- 再接受协助须**显式开启**；**不**自动恢复监听。

### 3.5 外框与布局（建议起点 · 非最终细则）

- **产品建议起点**（供体验细化，**≠** 已验收像素）：首次默认约 **840×600** 逻辑客户区；首次按实际工作区限制；之后切页 / 模式 / 连接**都不自动改外框**；允许用户拖拽。
- **建议**客户区宽 ≥760 双列、&lt;760 上下堆叠；内部滚动 / 重排可达，**不用**拉高窗解决业务页。
- 具体内部排版由**体验 + 客户端**在此边界内定；不以占满高度拉出空灰；**线框非视觉验收**。
- 业务 Agent/Helper 现有约 760×700 / 840×820 须适配**内部滚动**；200% DPI 小工作区主按钮可达。

### 3.6 分工与边界

| 角色 | 本轮 |
|------|------|
| **客户端** | **唯一执笔** `src-net48/RemoteAssist.App` 及必要 Agent/Helper 视图适配 / 状态绑定 |
| 服务端 | **不改** relay / site |
| 安装器 | **不混**本轮 |
| 迭代 | 协调；**独占** `iteration-status`（本收口文不改该文件） |
| 体验 | 对照视觉；**另写 A 细则**供全员复核 |
| 测试（各侧） | 按门禁出真实证据 |

### 3.7 明确不变 / 不做

- 安全 / 配对 / 信任档 / 凭证载荷门槛**不变**；R050 仍 **blocked**。
- **不**恢复免密 / 无人值守 / 多会话；**不**改「结束作废码」未来规格。
- 本轮范围外 **R049 仍未授权**（不借本轮全面解除）。
- **无** push / 生产 / 公网换包 / 安装到用户现用环境。
- **不得**关闭用户正在运行的程序或读取真实凭证；真实 UI 测试须已有授权隔离环境，若缺则写 **blocked**，**不编 PASS**。
