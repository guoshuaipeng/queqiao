## 体验目标（用户重申 · 2026-11-06）

> **产品意图**，与下方「当前安全主路径」分开。短码本身**不等于**已可安全连接。

1. **复制内容目标**：主路径只要 **`{会话码}-{8位验证码}`**（会话码 + 密码；验证码仍 8 位数字、保留前导零）。中继地址默认内置，仅在**高级设置**修改；亲友**不**复制服务器地址或长串载荷作为主路径。协助端一次粘贴短码即可连接——**仅当**「安全实现前置条件」满足之后。
2. **口述/展示**：短码仍可展示与口述；目标是复制与粘贴也走同一短形态，不再逼亲友转发完整 `remoteassist:pair` 长串。

## 安全实现前置条件（短凭证 · blocker）

- **当前**安全连接仍要求完整 `remoteassist:pair` 载荷（含 **Agent 业务 TLS 指纹 `fp=`** / `PairQrPayload`）。见下文「当前安全主路径」与 `docs/tls-trust.md`（R043 信任模型**不变**）。
- `{会话码}-{8位验证码}` 今日只授权中继会话，**不能单独**建立安全业务通道。
- **R050**（短凭证可连）**blocked**：待架构给出保留端到端身份验证的短凭证方案与迁移/兼容边界；未经验证**不得**宣称短码可安全连接。
- **禁止**：TOFU；跳过 / 降级校验；把中继回传、未经可信绑定的指纹当独立认证；为体验删掉地址或指纹后仍称短码可连。
- 体验目标与安全前置条件**分节落档**；实现轮不得把体验文案先行改成「只复制短码」却仍依赖完整载荷暗连。

## 用户目标（开放评估 · 非出货拍板 · 2026-11-06）

> **USER GOAL + OPEN EVALUATION**，详见 `docs/PRODUCT.md` 同名节。短码 / 唯一凭证**不是**已定出货路径。

- **评估目标**：code + password 为**唯一**控制凭证；服务端**不知**明文密码。
- **冲突**：与现网账号免密 / owner-token（`connect_device` / `ownerLink`）冲突；产品**未**决定保留旧免密；**禁止拍板兼容**；等用户经体验选 A/B。
- **正交**：写操作本机确认档位（权限三级 + 信任等级）不因本评估改动。
- **架构**：另评 PAKE（指针）；**R050** 仍 blocked。当前安全主路径（完整载荷 + `fp=`）不变。

## 当前安全主路径（R043 · 在前置条件满足前仍有效）

亲友/客户仍然 **一次复制、一次粘贴** 即可连接。剪贴板里必须是**可安全连接的完整字符串**（既有 `remoteassist:pair` 安全载荷形态，含会话码 + 密码 + **Agent 业务证书指纹**），不得发明新编码，也不得跳过指纹校验。

## 规则（已拍板 · 6 点 + R044 逐字）

### 1. 一次复制 / 一次粘贴；8 位验证码不变

- 主按钮文案（逐字）：**「复制连接凭证」**
- 复制内容 = **完整可连接字符串**，复用既有安全载荷格式（`PairQrPayload.BuildRelay` / `remoteassist:pair?v=2&via=relay&relay=…&code=…&pwd=…&tls=1&fp=…`）：含 **会话码 + 密码 + Agent 业务指纹**。
- **禁止**另发明编码；**禁止**跳过指纹校验。
- 新生成 / 刷新的验证码仍固定 **8 位纯数字**，字符串**保留前导零**；刷新会话码须同时换密码。

### 2. 被协助端（接受协助）复制话术（逐字）

- 引导：**「点「复制连接凭证」，把复制出来的整段发给要帮你的人。」**
- 复制成功：**「连接凭证已复制，请完整发给对方。」**
- 复制失败：**「未能复制，请选中完整连接凭证，手动复制后发给对方。」**  
  剪贴板失败时在界面**展示完整字符串**供手动抄写/选取，**不得**提示「已复制成功」。
- **禁止**把完整连接凭证写入普通日志、审计对外展示或异常 MessageBox 原文。

### 3. 协助端（去协助）单框（逐字）

- 主输入框标签：**「粘贴完整连接凭证」**
- 旁注/提示：**「把对方通过「复制连接凭证」发来的整段粘贴到这里。」**
- 动作按钮仍为 **「连接」**；不要拆成多次粘贴。

### 4. 短码 / 无安全验证信息旧两行：可识别，但必须阻断连接

- 短形态 `{会话码}-{8位验证码}`、历史两行「会话码：/验证密码：」等**缺少安全验证信息**的输入：可以识别其意图，但 **MUST 阻断连接**（在进入业务连接之前）。
- 阻断文案（对人话，**逐字**）：  
  **「连接凭证缺少安全验证信息，暂时无法连接。请让对方点击「复制连接凭证」，重新发送完整内容。」**
- **禁止**「忽略 / 继续 / 仍要连接」类绕过；**禁止** TOFU、自动降明文、`skipTls`、无指纹 `Insecure=true`。
- **验证不匹配 ≠ 缺少验证信息**：不匹配按既有安全失败处理，不得用缺失提示覆盖，不得自动信任。

### 5. 短「会话码-8位验证码」仅展示 / 口述

- 若界面仍展示短码便于核对或口述：仅作**展示/核对**，旁注 **「连接时请发送完整连接凭证」**。
- **不得**提供与「复制连接凭证」同权的「只复制短码」主按钮；短码**不能单独完成连接**。

### 6. 亲友可见界面用语（R044）

- 默认说明、错误、复制反馈及对应 Hint：**不得**出现「指纹」「fp」「TLS」「安全载荷」等技术词。
- 对人使用：**「完整连接凭证」**、**「安全验证信息」**。
- 诊断文档可保留技术名词；普通日志不输出完整凭证。
- 不得因改文案而隐藏错误或降低验证要求。

### 7. 验收备忘

- Win / Avalonia / CLI：从「复制连接凭证」得到的**完整字符串**，一次粘贴走既有安全路径可连（含 `fp=` 钉扎）。**运行验收另计**（R043 仅编译/文档 PASS_WITH_NOTES）。
- 新密码 8 位数字、保留前导零。
- **缺少安全验证信息**时在业务连接前阻断（见第 4 点逐字文案）。
- **篡改 / 不匹配**不得绕过校验；与缺失分两类提示。
- 剪贴板失败 ≠ 成功提示（见第 2 点失败句）。
- 完整凭证不进普通日志。
- R044：界面字符串须与上文**逐字**一致；亲友 UI 无技术词。

## 鉴权与协议

- 中继控制面仍为 `guest_host` / `guest_join` 的 code + password；**不新增中继协议字段**。
- 业务 TLS：**端到端到被控 Agent 临时自签证书**；`fp=` 是该业务证书指纹（`CreateEphemeralServerCert` / `PairQrPayload`），**不是**中继证书。中继 `:17891` 为明文 TCP JSONL → 透明 pipe，**不终结**业务 TLS。
- **禁止**客户端「内置官方中继业务指纹」方案（仓库无此常量，且与架构不符）。
