## 设计说明（≤40 行）

### A. 一键复制「会话码 + 密码」

- **痛点**：协助闭环里被控方最高频动作是把凭证发给协助方；现有「复制会话码」不含密码，「复制载荷」是 URI、亲友不好念。
- **位置**：被控端「分享给协助方」区，在「复制会话码」旁新增主按钮 **「复制码+密码」**（或把该按钮提升为该区默认主操作）。
- **剪贴板格式**（纯文本，两行）：
  ```
  会话码：{code}
  验证密码：{password}
  ```
- **状态栏**：`已复制会话码和验证密码。`
- **不变**：现有「复制载荷」「复制 MCP 配置」「复制会话码」保留。
- **验收**：点按钮 → 剪贴板两行正确 → 状态栏成功；连续连点 3 次不崩；刷新会话码后再复制为新码+新密。

### B. 品牌文案统一

- 窗口标题 / 顶栏：`鹊桥` 或 `鹊桥远程协助 · 智能体`（短标题用「鹊桥」）。
- 副标题保持中继语义，去掉过时「LAN session」表述（截图时代残留）。
- 安装包显示名（Inno `AppName`/`AppVerName` 等用户可见处）改为「鹊桥远程协助」；内部 exe 名可暂不变，避免本轮扩 scope。
- **验收**：冷启动窗口标题含「鹊桥」；主界面不再出现作为产品名的「远端协助」四字（日志字段名除外）。
