## 用户确认原句

同意：被协助窗底部保留结束按钮，结束只断开、旧码仍可再用；旁边增加本机改动回看，点开在同窗查看，结束后也能看刚才记录，不上传云端。

## 行为锁定

### 结束这次协助

1. 被协助窗**底部**轻按钮「结束这次协助」（非实心主按钮；「复制码+密码」仍唯一实心主按钮）。
2. 点后本机确认；**取消 = 零副作用**（不改连接、不改码、不改列表）。
3. 确认后：**只断开**当前已配对会话；**不** `Stop` 监听；**不**作废会话码/验证密码（未刷新则旧码仍可再用）。
4. 结束后**留在**接受协助窗（可继续复制码、可打开回看）；不强制回首页、不退出进程。
5. 状态人话须写明已结束且旧码仍可再用（对齐 `docs/quality-after-disconnect.md` 被协助端本机结束口径）。

### 本机改动回看

1. 结束按钮**旁边**入口「本机改动回看」。
2. 点开后在**同一窗口**展示只读列表（标题「本次协助已确认的改动」）；不新开独立主窗、**不上传云端**。
3. **结束后仍可打开**查看刚才记录（读本机审计；列表筛已确认/自动允许，排除未确认与已拒绝）。
4. **批准 ≠ 执行成功**：列表展示「已确认」等人话，不得把仅批准写成执行成功；执行结果仍以审计 `tool_ok` / `tool_error` 为准（本列表不冒充成功）。

## 明确不做

- 零副作用结束（结束必须真正断开已连会话）。
- 多码并列 / 无人值守 / 长久码（见 S006 等，另轮）。
- 把 R049 单主窗口标为已体验验收。
- 三档信任 UI、免密旁路、云端工单。
- 本机启动应用做 UI 验收（实现轮用隔离快照 publish 验证编译）。
