R015 已产品验收设备列表人话与免密连接可点击态。Avalonia 协助端连上后常用操作仍少于 Windows，且「运行一条命令」不像给亲友看的措辞；已连接后「连接：{名称}」仍实心绿，和常用操作抢主按钮权重。本轮把协助端连上之后的操作对齐 Windows 质感，不扩协议。

## 本轮目标

1. **高频**：Linux Avalonia 协助端对齐 quality.md §3 / Windows Helper.UI——未连接不展示「常用操作」；连上后展开；按钮白话为「查看正在运行的程序」「查看文件夹」「查看日志」「查看文件」「提议一项改动」；「常用操作」标题下加一句轻引导「建议先看正在运行的程序，再决定要不要改」。已连接时账号区「连接：{名称}」不再保持实心绿主按钮（改为已连接轻态或禁用「已连接」），会话码区「连接」保持已连接时的灰禁用。
2. **打磨**：免密成功文案、R014/R015 账号标签与设备列表人话、R013 已确认列表与刷新确认原文一律不改；若路径输入框（文件夹/文件）需要，跟 Windows 一样用轻量提示，不要弹控制台味对话框。

## A. 连上后五键 + 引导（高频）

验收：
- 未连接（含仅登录未免密连上）截图里看不到「常用操作」整块（含灰按钮）。
- 访客会话码连接成功，或账号免密连接成功后，展开「常用操作」，顺序与文案：
  1. 查看正在运行的程序
  2. 查看文件夹
  3. 查看日志
  4. 查看文件
  5. 提议一项改动
- 标题下有轻引导：「建议先看正在运行的程序，再决定要不要改」（或同等人话；不要出现 ListProcesses、MCP、Assist）。
- 「提议一项改动」走既有写确认；拒绝后仍是「已拒绝，未做任何改动」。只读四项不弹写确认。
- 已连接后，账号区连接按钮不再是实心绿「连接：{名称}」主权重（建议文案「已连接」或灰禁用「已连接：{名称}」）；旁注可保留免密说明，不要再像「点我去连」。
- 界面不出现 Assist、Admin、ownerLink、TLS、端口号、内部 id。品牌「鹊桥」。
- osx 能出包即可；未上真机就注明，不写成 Mac 已验收。

截图放到 `docs/screenshots/r016-*`（至少：未连接无常用操作；免密或访客已连接后五键 + 引导；已连接后连接按钮非实心绿主权重；提议一项改动的写确认或拒绝审计其一）。
