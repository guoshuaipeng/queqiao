QueQiao Remote Assist (Windows primary path · net48)

This setup is a framework-dependent small package, not a self-contained large package.

Requirement: .NET Framework 4.8 must already be installed on this PC.
If the app reports a missing .NET Framework when you open it, install it first:
https://dotnet.microsoft.com/download/dotnet-framework/net48

Notes:
- Main program after install: RemoteAssist.Net48.exe (Accept assist / Assist others)
- Same folder includes RemoteAssist.Mcp.exe (MCP host for Cursor etc.; config must include full secure credential/fingerprint; missing fp must not fall back to cleartext)
- If the website still links to the older RemoteAssist-Setup (net8 self-contained), that is a compatibility backup. For friends/family, prefer RemoteAssist-Net48-Setup.
