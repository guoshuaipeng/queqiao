如何使用

第一次怎么用

双方都在电脑上打开鹊桥，按自己的角色做三步。

我需要帮助

需要帮助的人

  1. 1
    打开鹊桥，开启接受协助

    在自己的电脑上操作。

  2. 2
    私下发送完整连接凭证

    只发给信任的人，不要只发片段，也不要贴到群里。

  3. 3
    结束后在本机停止

    停止接受或结束本次协助。

我来帮忙

来帮忙的人

  1. 1
    打开同一款鹊桥

    在自己的电脑上操作。

  2. 2
    整段粘贴凭证，点击「连接」

    不会自动连接；凭证不对请让对方重新复制。

  3. 3
    完成后断开

    断开或离开本次会话。

安全与隐私

只和信任的人协助

我们不做“绝对安全”“零风险”这类无法核实的承诺，下面这些需要双方一起注意。

保管好连接凭证

私下发给信任的人，不要贴到公开评论、聊天群或截图里。

结束不等于凭证作废

结束连接不代表凭证永久失效，请继续妥善保管。

帮助

常见问题

手机能装吗？

不能。手机可以阅读本页说明，请在电脑上下载和使用。

怎么把问题交给 AI 智能体？

在「去协助别人」里复制 MCP 配置，贴进 Cursor 等支持 MCP 的工具的设置里。智能体可以查进程、读日志、浏览目录和读文件；要执行命令时，必须由对方在本机点允许，智能体也不能绕过。

需要帮助和来帮忙是两个软件吗？

不是，是同一个程序，只是用法不同。

提示凭证不对或不完整？

请对方重新复制完整凭证再整段粘贴，不要自己改内容。

点了连接但没连上？

检查网络，确认双方都已打开鹊桥、需要帮助的一方已开启接受，稍后重试。不要按来路不明的说明关闭安全软件。

打开安装包提示缺少运行环境？

推荐包需要 .NET Framework 4.8，先在 微软官网 安装后再试；也可以改用备用包。

怎么结束协助？

需要帮助的人在本机停止接受或结束协助；来帮忙的人断开或离开会话。
