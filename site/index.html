如何使用

第一次怎么用

两种用法，同一个软件：帮亲友临时看一下，或者连自己不在身边的电脑。

双方都在电脑上打开鹊桥，按自己的角色做三步。不用注册账号。

我需要帮助

需要帮助的人

  1. 1
    打开鹊桥，开启接受协助

    在自己的电脑上操作。

  2. 2
    私下发送完整连接凭证

    只发给信任的人，不要只发片段，也不要贴到群里。

  3. 3
    结束后在本机停止

    停止接受或结束本次协助。

我来帮忙

来帮忙的人

  1. 1
    打开同一款鹊桥

    在自己的电脑上操作。

  2. 2
    整段粘贴凭证，点击「连接」

    不会自动连接；凭证不对请让对方重新复制。

  3. 3
    完成后断开

    断开或离开本次会话。

家里、公司或机房的电脑，人不在旁边也想连上去查问题。在那台电脑上开启无人值守，生成长久码；之后用这份连接凭证就能连，不用注册账号。

被连的电脑

先在这台电脑上设置好

  1. 1
    打开鹊桥，开启无人值守

    本机会说明风险并请你确认。开启后会生成长久码（可长期使用，直到你撤销）。

  2. 2
    复制连接凭证，放到你信任的设备上

    谁拿到这份凭证都能连上这台电脑，请不要发到群里或公开地方。

  3. 3
    保持鹊桥在运行

    可关到托盘。电脑关机或鹊桥退出后，暂时连不上。

你手边的电脑

需要时直接连

  1. 1
    打开鹊桥

    在「我帮别人」里整段粘贴那台电脑的长久连接凭证。

  2. 2
    点「连接」

    无人值守下不会再弹「允许协助」；对方也不必守在电脑前。

  3. 3
    排查完断开

    改动也不会再弹窗询问，但仍会记在被连电脑上。用完请断开。

长久码适合连自己的电脑；帮亲友临时看一下请用「开启接受协助」的临时凭证。被连电脑关机或鹊桥没开时，连不上。可随时在本机撤销长久码。

安全与隐私

只和信任的人协助

我们不做“绝对安全”“零风险”这类无法核实的承诺，下面这些需要双方一起注意。

保管好连接凭证

私下发给信任的人，不要贴到公开评论、聊天群或截图里。

结束不等于凭证作废

结束连接不代表凭证永久失效，请继续妥善保管。

无人值守要本机打开

装上、开机都不代表能被连。必须在那台电脑上亲手开启无人值守并保管好长久码；随时可在本机撤销。

帮助

常见问题

手机能装吗？

不能。手机可以阅读本页说明，请在电脑上下载和使用。

怎么把问题交给 AI 智能体？

在「去协助别人」里复制 MCP 配置，贴进 Cursor 等支持 MCP 的工具的设置里。智能体可以查进程、读日志、浏览目录和读文件；要执行命令时，必须由对方在本机点允许，智能体也不能绕过。

人不在电脑旁边，也能连上吗？

可以，用无人值守：在那台电脑上开启无人值守，复制长久连接凭证；之后在另一台电脑粘贴该凭证连接即可。那台电脑要开着机、鹊桥在运行。不用注册账号。

无人值守时，对方能直接改我的电脑吗？

可以。开启无人值守后，连上不必再点「允许协助」，改动也不会再弹窗；每次改动仍会记在那台电脑上。请只把长久码放在你信任的设备上，不用时可以撤销。

无人值守和发凭证给亲友有什么区别？

临时凭证适合帮亲友当场看一下：连上要对方点允许，结束就作废。长久码适合连自己的电脑：开启无人值守后可反复使用，连上和改动都不再弹窗，也不用注册账号。

可以部署在自己公司的服务器上吗？

可以，支持私有化部署。部署方法见 GitHub 仓库。

需要帮助和来帮忙是两个软件吗？

不是，是同一个程序，只是用法不同。

提示凭证不对或不完整？

请对方重新复制完整凭证再整段粘贴，不要自己改内容。

点了连接但没连上？

检查网络，确认双方都已打开鹊桥、需要帮助的一方已开启接受，稍后重试。不要按来路不明的说明关闭安全软件。

安装包打不开？

Windows：浏览器拦截时选择保留，然后重新打开安装包，不用先装运行库。macOS：若提示来自未识别的开发者，请到「系统设置 → 隐私与安全性」里允许打开；也可按住 Control 点图标选择打开。

怎么结束协助？

需要帮助的人在本机停止接受或结束协助；来帮忙的人断开或离开会话。
